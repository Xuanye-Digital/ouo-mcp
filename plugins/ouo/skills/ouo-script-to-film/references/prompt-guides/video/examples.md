# 描述示例

例中的时长、画幅、风格、角色和声音条件只属于该案例，不是默认参数。代码块中的文本是提示词正文。

引用示例中的 `@图片/视频/音频+编号` 为展示写法，使用时须对应真实素材；画布保存通过 `set_prompt.parts` 插入原生引用，模型请求按实际契约编译。

## 1. 对话场景：用停顿与细节呈现关系变化

**输入条件**：8 秒，年轻女子发现店主隐瞒了实情；不生成字幕和配乐。

**提示词正文**：

```text
黄昏的旧书店内，窗外侧光落在木柜台边缘，书架深处保持昏暗。年轻女子站在柜台左侧，右手翻动摊开的账册；店主位于柜台右后方，隔着柜台面向她。

0-3 秒：双人中景，摄影机缓慢靠近。女子看到其中一页，翻页的手忽然停住，随后抬眼看向店主。

3-5 秒：延续双人中景，摄影机停止靠近。店主避开她的目光，拇指摩挲柜台边缘，女子看着他，嘴角收紧。

5-8 秒：切女子近景。她短暂停顿，再用平静而压低的声音说：“你早就知道了。”说完仍看着店主，没有向前逼近。画面保留翻动纸页、衣袖摩擦和店内低弱环境声，无字幕、无配乐。
```

女子停住翻页、店主回避目光和最后的压低声线，依次呈现发现、回避和质问。

## 2. 单镜头：用动作与焦点表达信息

**输入条件**：裁缝完成检查后确认布料合格，安静写实。

```text
傍晚的裁缝工作间，暖色台灯从侧面照亮木桌，后方悬挂的布料落在柔和暗部。老裁缝坐在桌边，手指捏着布料接缝，先轻轻拉开，再顺着针脚摸过一遍。

摄影机保持在他的侧前方近景，焦点先落在手指与接缝上，待手指停住后缓慢转到脸上。老裁缝低头看着针脚，眉间逐渐放松，轻轻点头，嘴角浮起很浅的笑意。只保留布料摩擦和工作间里的低弱环境声。
```

这个变化由焦点转移完成，不再额外叠加环绕、变焦和推镜。

## 3. 多镜头：建立、变化与回应

**输入条件**：15 秒，老人挂好树牌后，车从村口驶过；无对白、无配乐。

```text
写实乡村短片，深秋午后，暖金色侧光照在村口老槐树上。老人刚把红色保护牌固定在树干上，牌子两侧的绑绳绷紧，脚边散着落叶。

0-4 秒：固定全景。老人站在树旁收回双手，稍退半步看着牌子，肩膀渐渐放松。路口先传来低沉的引擎声，车辆尚未入画。

4-10 秒：切侧面中景，老人位于画面左侧，土路从右侧通向远处。一辆越野车从右侧驶入，经过树旁后继续沿土路远去。车带起的气流先吹动衣摆，再掀起几片落叶，树牌轻轻晃动；老人本能地抬起手臂挡住扬尘，身体没有离开树旁。

10-15 秒：切手部近景。老人放下手臂，伸手扶正晃动的牌子，拇指擦掉牌面的一点浮灰。引擎声随车辆远离逐渐减弱，树叶摩擦声重新清晰。全段无对白、无字幕、无配乐。
```

每个镜头只承担一个主要变化；“车驶过”有进画、经过和远离的完整轨迹。

## 4. 产品与美食：让材质参与动作

**输入条件**：展示热茶倒入玻璃杯的过程，重点是液体、器物和水汽。

```text
干净的木质茶台上，一把素色陶壶位于画面右侧，透明玻璃杯位于左侧。柔和侧光穿过杯壁，在桌面留下浅色反光，背景茶具轻微虚化。

采用固定近景，同时保留壶口与完整杯沿。右手握稳壶柄，缓慢抬起并倾斜陶壶，细窄茶流准确落入杯中。杯底的茶汤先形成一圈旋转水纹，液面随注入逐渐升高；暖色茶汤透过杯壁显出深浅层次，细薄水汽向上升起后慢慢散开。接近半杯时，手腕回正，茶流逐渐变细并收住，壶口没有连续滴落。手将陶壶缓慢放回原处，保留倒茶声与陶壶轻触桌面的声音。
```

不把“温暖、香、好喝”当作可见动作，改写成茶汤、水汽、反光和操作细节。

## 5. 水墨：让风格体现在运动机制中

**输入条件**：宣纸淡彩水墨，展示古代粮仓，动作克制。

```text
宣纸淡彩水墨动画。地下粮仓剖面横向展开，多座圆形粮窖装满金黄粟米，远处仓城建筑以淡墨渐隐，纸张纹理始终可见。

镜头缓慢向右平移，依次显出窖口、木槽与推车工人。谷物沿木槽连续流入粮窖，在堆顶形成细小滑落；工人推车时身体稍向前倾，车轮缓慢转动。窖边官吏停步俯看，再轻轻抬手示意继续运粮。人物与建筑保留平面手绘轮廓，墨色在边缘轻微晕开，淡彩层次温润，不出现立体塑料高光。声音为低弱车轮声和谷物落下的细响。
```

## 6. 局部编辑：目标变化与保留范围

**输入条件**：原视频天空太空，换成有体积的蓝天白云；其他内容保留。

```text
只替换原视频的天空区域。新天空为自然浅蓝色，多组积云分布在画面左、中、右和远处，云团大小与远近关系清晰，朝光一侧明亮，背光面保留柔和灰影。云的外轮廓有起伏，避免一条横贯画面的平直云带。

云层缓慢移动，始终位于建筑和树木后方，遮挡边缘随原视频运动自然变化。新天空的光照方向、曝光、色温、景深、颗粒和运动模糊与原画面匹配。建筑、人物、树木、地面和车辆不重绘、不移位；保留原视频的构图、摄影机运动、剪辑节奏和声音。
```

## 7. 续接：承接一个尚未完成的动作

**输入条件**：上一段结束时，女子右手握着门把，身体侧对门口，门刚打开一条缝；摄影机在女子左后方近景缓慢靠近，屋内暖光透出，钟声仍在回响。

```text
延续女子右手握住门把、身体侧对门口的姿态，门保持刚打开一条窄缝的状态。摄影机维持在女子左后方近景，屋内暖光沿门缝落到她的手背上，钟声仍在回响。

女子握稳门把，沿原来的方向继续缓慢推门。随着门缝扩大，摄影机沿原方向轻微靠近，先显出屋内木桌的一角，再露出桌面上的木壳座钟。女子听见回声减弱，推门的手停住，身体略向前探，视线落在座钟上。结尾门仍开着，女子仍握着门把，给下一镜保留观察钟面的动作起点。
```

## 8. 循环：让状态与运动同时闭合

**输入条件**：果园直播背景，固定机位，轻微风，无新增主体。

```text
固定机位的冬枣果园中景，前景枝叶、中景果树和远处种植行形成清晰层次。白昼自然光柔和稳定，冬枣大小真实，果实基本保持稳定，枝叶保留自然纹理。

轻风让近处少量叶片沿同一条小幅弧线缓慢摆动，枝条轻微跟随，远处树冠变化更弱。所有摆动逐渐回到开头的位置和运动相位，末尾与开头的速度、方向连续；摄影机位置、构图、曝光、色温和背景均保持一致。只保留连续的轻微风声与叶片摩擦声，环境声在循环连接处也自然衔接。画面没有进出场人物、采摘动作或突然出现的物体。
```

## 9. 反打与切回：引用跟随人物和道具

**输入条件**：甲的外观图、乙的外观图、钥匙图、门口场景图，以及甲的音色样本均已确认；两人交接钥匙，甲说“收好了”，乙不发声。以下为虚构示范，不是生产原文。

```text
门口场景@图片4，甲在门左侧，乙在右侧，两人隔一步相对。门框与灯的位置保持场景依据，三镜在同一轴线侧拍摄。

镜头1，过乙@图片2的肩拍甲@图片1。甲低头看一眼右手的钥匙@图片3，将它递到两人之间，抬眼看向乙。甲用音色@音频1低声说：“收好了。”乙的肩背留在虚焦前景；音频只提供甲的音色，台词采用本段原句。

镜头2，同侧反打乙@图片2，保留甲@图片1的肩部在前景。乙先看向钥匙@图片3，再伸出左手，手指接稳钥匙后甲才松手。只听到一声轻微金属碰响，乙没有开口。

镜头3，切回甲@图片1近景。甲确认乙@图片2已将钥匙@图片3收在左手，空着的右手落回身侧，肩膀稍微放松。门口环境声持续，结束时钥匙仍在乙左手。
```

引用在反打、切回与交接处重新明确归属，同一动作段内仍可自然使用称呼。没有为重复引用增加人物或复制钥匙。

## 10. 多参考分工：产品外形、动作与声音分别取用

**输入条件**：同一保温杯的正面图与背面图、手持转杯动作视频、旁白音色样本；展示杯身标识与背面结构，旁白原句“看这一处”。以下为虚构示范。

```text
同一只保温杯以正面@图片1、背面@图片2为外形依据，保留原有标识和结构。动作视频@视频1只提供握持位置、转动顺序与节奏，不采用原视频的杯子外形、字幕、台词和声音。

固定近景，手握杯身下部，正面@图片1朝向镜头，标识不被手指遮住。沿@视频1的握持动作平稳转杯，手指随转动调整，杯子始终留在同一只手中，另一只手不入画。

杯身转到背面@图片2时减速停住，焦点落在背面结构上。旁白用音色@音频1平静地说：“看这一处。”仅取音色，使用这里的原句。说完保留稳定展示，杯子不再转动，照明和背景保持连续。
```

多视图描述同一件产品。参考分工限定到属性，动作发生处和背面展示处仍分别引用；没有将所有素材只列在开头。

## 11. 一镜到底：全局质感、内部节拍与针对性约束

**输入条件**：10 秒，甲把确认无误的钥匙交给乙，甲说“就是这把”；两人外观、钥匙和门口场景参考已确认。用户要求电影写实、8K 超清质感，无新增字幕和配乐。以下为虚构示范。

```text
电影写实，8K 超清质感，保留自然肤质、衣料纹理与钥匙的金属反光。门口场景@图片4，暖色门灯从侧上方照亮两人的脸和手，高光不过曝，暗部保留衣料层次。甲在左、乙在右，隔一步相对，门框位置稳定。全段为同一连续镜头。

0-2 秒：双人中景，甲@图片1低头核对右手中的钥匙@图片3，乙@图片2看向钥匙，左手尚未伸出。摄影机保持位置，门外低弱雨声持续。

2-5 秒：甲@图片1抬眼看乙，轻声说：“就是这把。”右手将钥匙递到两人之间。摄影机沿原轴线侧缓慢推进，构图仍保留双方的手，乙伸出左手。

5-8 秒：焦点落到钥匙@图片3与两人的手上。乙@图片2用左手手指接稳后，甲@图片1才松手，发出一次轻微金属碰响；钥匙随乙的左手收向胸前，甲的右手落回身侧。

8-10 秒：摄影机停止推进，乙@图片2握住左手中的钥匙@图片3，甲确认交接后肩膀放松。两人保持原站位，门外雨声延续，结尾保留这一交接完成状态。

约束：钥匙始终只有一把，不复制、不跳到另一只手；手指与钥匙接触关系连续。全程不切镜、不跳换站位，不出现额外台词、新增字幕或配乐。
```

四个时间段仍是一个镜头；起始核对、短句、接稳与收势分别留时。正文的“8K 超清质感”是用户要求的视觉方向，实际输出分辨率另按所选模型的参数保存与核对，不能据此声称输出 8K。

## 12. 三维产品动画：选用共性，不套用写实禁词

**输入条件**：8 秒，展示同一盏台灯点亮并转到背面的过程；用户选择三维动画、清晰材质、轻柔电子配乐，保留底座原有品牌标识，不新增字幕。正面图与背面图均已确认。以下为虚构示范。

```text
精致三维产品动画，同一盏台灯以正面@图片1、背面@图片2为外形依据。灯臂、转轴与底座比例保持一致，拉丝金属纹理清晰，柔和顶侧光让边缘高光连续，背景为干净的中性灰。保留底座原有品牌标识；轻柔电子配乐贯穿。

0-3 秒：正面@图片1中近景，台灯立在桌面中央，底座固定。灯罩内的暖光逐渐亮起，照亮下方桌面，灯体不移动；金属表面仍保留柔和反光。

3-6 秒：摄影机从正面沿台灯左侧平稳绕行半圈，逐渐显出背面@图片2的转轴结构。灯罩保持点亮，底座与桌面接触位置不变，灯臂不自行弯折。

6-8 秒：摄影机在背面@图片2停住，对焦转轴与拉丝表面，保留清晰稳定展示。亮度与配乐连续。

约束：只有一盏台灯，多视图不生成多件产品；灯臂和转轴不变形，金属纹理不闪烁。保留原有品牌标识，不叠加字幕、水印或额外文字。
```

本例保留三维媒介、配乐与原有标识，负面约束只针对数量、结构、纹理和新增文字，没有套用“禁 CG”“无音乐”“禁止任何文字”。
