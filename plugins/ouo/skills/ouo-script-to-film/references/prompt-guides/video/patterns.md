# 分模式写作

按当前任务使用对应章节，重点说明该模式需要的画面变化与镜头组织。基础规则见 `get_video_prompt_guide(params={"section":"writing"})`。

## 单镜头与微表演

先确定观众这一镜应看见的变化，再安排主体和摄影机。描述顺序可以是场景与起始构图、主体状态、一个动作链、最终落点及必要声音。

微表演适合近景、特写和较克制的运镜。用一个主要表情变化配合少量肢体动作，不要求同一秒内同时完成抬头、落泪、起身、转身和出门。

推进可以用来揭示表情，后退可以逐渐暴露空间关系，横移可以显出遮挡后的对象。固定构图也能通过主体进出画、焦点转移或前后景动作形成信息变化。

区分“移动摄影机”“光学变焦”“改变焦点”。只想把注意力从前景道具转到后景人物时，描述焦点转移，不额外增加一段推摄。

## 同一镜头内的时间节拍

一个镜头可以包含多个时间段。已知时长并有起手、察觉、回应或收势等转折时，默认将它们分配到连续秒段；段与段之间延续同一摄影机路径、场景和人物状态，只有需要剪辑时才写切镜。不要把“一镜到底”理解成不写时间。

每个节拍选择当前需要的动作、目光或重心变化、焦点与声音，交代段末状态；不要求每一秒都安排新动作。准备与接触、停顿与反应、说话与听者反应可以占据不同长度，也可明确并行。时间线覆盖片段全长，不用长台词或过密调度填满短窗口，末段按需要留出稳定展示或延续运动。

若同一条画面时间线上还要标镜内台词窗口，用“本段内某时刻开始说”或独立声音轨说明，避免把重叠时间误当成重复镜头。未知时长使用先后与相对停顿；用户已有格式时沿用并核对节拍，无需另造秒数。

## 多镜头与对白

先确定本段从什么冲突或信息开始，到什么结果结束。镜头围绕这些节点组织，例如建立关系、发出动作或问题、给出回应。不是每段都需要全景开场或反复正反打。

按当前画面需要标注景别、主体位置、动作与表演、台词或音效。相同全局风格只写一次，后续只写发生变化的部分。

默认可将实际对白与同期镜头、动作和语气写在一起，例如“近景，甲停下翻页，抬眼看向乙，压低声音说：‘你早就知道了。’乙避开目光”。用户或所选 Skill 采用声画表、台词轨或模型结构化格式时保留其写法，核对说话者、实际原句、时间和画面是否明确对应；不因分列而判不合格。环境底噪等贯穿声音可统一说明。

两人对话先固定人物位置、面向和视线目标，再选机位。改变角度时维持交互关系和视线匹配，不把不同角度下的画面左右硬当成世界坐标。说话者的动作与听者反应要区分，允许台词跨切镜延续。

有参考时，在每次切镜、反打和切回处重新标明相关人物的引用。例如“过乙@图片2的肩拍甲@图片1”，再写甲的动作；下一镜“同侧反打乙@图片2”，明确此时看谁。前景人物、被摄主体和说话者可以不同，音频引用跟随发声归属。相同身份复用同一来源，不能只在总述列出两个人后便省略所有后续引用。

对白必须保留原句时，检查表演和时长是否容得下；不足则简化次要调度，或提出延长、拆段的明确建议。不要仅靠“快速说完”消除拥挤。

风格按用户目标与所选 Skill 应用于当前场景，检查是否存在具体冲突，不因偏离内置示例而改写。需要完整示范时再读 `section=examples`；示例的人物、台词和参数不进入用户故事。

## 全局要求与局部约束的配合

全局总述选定媒介、视觉质感、光线色彩和贯穿声音，具体节拍只写发生的变化。明确哪些参考提供身份或空间，照明和当下状态按本段场景安排；特写中的肤质、衣料或产品材质只写本镜可见部分。保留需要的“高清”“8K 质感”“真实摄影感”，补足可见依据，实际规格按模型参数核对。

负面约束围绕这一段的失败风险选择：交接防止道具复制或提前换手，路径动作防止逆向或瞬移，反应镜头防止直接跳到最终情绪，局部编辑防止改动保留区域。通用的防变形、防闪烁等要求按画面相关性选用。画面若需要手、产品标识、配乐或三维动画风格，就不能同时禁止它们。

## 产品与美食

把需要展示的卖点写成可见的材料、结构或过程，例如液体怎样从壶口流出、杯壁如何凝出水汽、金属边缘如何反射侧光。气味、口感和“高级”要转成可见线索，不能只列形容词。

主体外形、相对尺寸和操作顺序稳定；涉及手部时明确哪只手在握什么、另一只手是否入画。镜头应能看见关键接触位置，不让特写与全套复杂操作争抢空间。

食材、液体、蒸汽与光照互相匹配。近景展示质地时减少无关大动作；需要展示产品整体结构时保留完整轮廓，不强行全程微距。

少量材质词就能表达清楚时，不再叠加互相打架的实拍、塑料、陶土、毛毡、平面水墨和照片级皮肤等风格。

使用产品多视图时先说明它们属于同一件产品，按出现的角度就地引用。动作视频只负责已选择的操作顺序或镜头路径，产品图负责外形和标识；必要时明确不采用原视频中的产品、文字及声音。握持、转动、交接和落桌处分别交代手与物的关系，结尾保留可辨认的稳定展示，不因多张参考变出多件产品。

## 空镜、水墨与其他风格

空镜也有事件：风经过树冠、雾从山谷抬起、落叶触水形成涟漪。写明哪些层次在动、各自方向和速度，摄影机是在移动还是锁定。

风格要影响描写方法。水墨可以通过渗化、留白、笔触层次和轻微的平面运动表达；毛毡通过纤维、缝线、柔软体积与克制形变表达；写实通过材料、受力、皮肤或织物的相应细节表达。按用户目标选择，不把所有风格混为“高清”。

使用墨色、光带或烟雾转场时，写清起点、遮挡或变化过程、落到的新画面；不能只说“自然无缝转场”。跨地点、跨年代的连续视觉转场须把变化机制写明，不能同时声称严格的实拍空间连续。

## 续接与首尾帧过渡

接续前一段时，确定结束时的人物姿态、位置、面向、持物状态、正在发生的运动、摄影机状态、光线和声音。接下来先延续尚未结束的动作，再引入新事件。

写清需要继承或达到的可见状态。已完成的动作不重新播放，不能一接续就重置站位、手中物品或运动方向。

从指定首帧过渡到尾帧时，写出中间可理解的动作或形变路径。两端状态跨度过大时减少中间事件或建议拆段，不用“瞬间无缝”掩盖跳变。

结尾给出明确交接状态，例如手仍握住门把、门开到一半、摄影机保持同方向跟随。不要在用户要求继续运动时默认结尾冻结。

承接视频时，在延续动作旁引用准确前段并说明采用的结束状态；人物和道具再次成为画面重点时仍引用各自来源。前段动作参考不自动覆盖已确认的身份、服装、空间或音色，也不重播已经完成的动作。

## 无缝循环

先选择可闭合的动作：呼吸、轻微摆动、绕固定路径运动等。开合动作需要明确回程；不可逆的进食、倒空、离场或破坏不能未经设计直接声明首尾一致。

末尾应回到与开头一致的位置、姿态、构图、光线和运动相位，连接处速度与方向连续。摄影机有运动时也要有闭合路径；否则采用固定机位或调整动作设计。

避免在结尾突然倒放、定格或跳回原位。多角色循环分别检查状态闭合，不能只让其中一个角色归位。

## 局部视频编辑与替换

先写唯一的修改目标与范围，再写目标变化、和原画面如何融合、哪些属性保留。表达要支持核对：天空替换须限制在天空区域，角色替换须说清是身份、服装还是整个身体外观。

锁定非目标区域时具体说明构图、位置、表演、镜头节奏和声音中哪些不变。新元素的透视、遮挡、光照、颗粒和运动模糊匹配原画面，不顺带重绘其他区域。

如果用户同时要求“原片光线完全不变”和“整体改成另一种照明”，先处理这个范围冲突。只改局部时，通常让新局部匹配保留部分；全局调色须有用户明确意图。
