# 视频提示词写作

把用户的意图写成可观察、能按时间发生的视听过程。画面、时间节拍、声音、全局视觉要求与必要约束共同组成提示词；画质和风格描述可以保留，并落实到当前主体、光线、材质和运动。

使用参考素材时，引用是正文表达的一部分。既交代参考对应关系，也在分镜实际使用处就地引用；不能只在开头列一次，后面的动作和反打全靠模型猜。

新编写或获准改写视频提示词前，默认读取并应用本章。仅搭工作流或只交付提示词同样适用，复用本次已读内容。用户本次要求、提供的提示词与指定格式优先，用户明确指定其他写作 Skill 或写法时采用其选择。仅保存或直接使用用户原文时保留正文。审阅关注用户目标、所选写作依据、事实与约束一致性及模型可执行性。

## 理解任务

常规单镜头按本章直接编写。多镜头、续接、循环或局部编辑需要具体写法时，读取 `section=patterns` 的相关内容。

保留已给定的剧情、人物身份、年代、风格、台词原句、时长、画幅和必须发生的事件。没有指定的时长、画幅、焦段、分辨率、模型和配乐，不套用固定默认值。

抓住本段的一个主要事件及其变化：从什么状态开始，发生什么，最后停在哪里。信息足够就直接写；仅在主体身份、关键动作或硬约束无法确定时提出简短澄清。必要假设放在正文之外。

先确定观众在这一段获得什么信息，以及情绪怎样改变，再安排可见动作。例如先让观众看见桌上的异常，再让角色发现，最后保留反应；不要把“观众信息差”“情绪目标”等分析标题原样堆进可直接生成的正文。

## 全局视觉与通用要求

全局描述为整段建立共同依据，按题材选择有关项目，放在简短总述中；后文写变化与局部例外。没有指定的风格不从示例套入。

| 维度 | 怎样写得有效 |
| --- | --- |
| 媒介与成像风格 | 明确实拍写实、三维动画、毛毡、手绘或水墨等方向；“电影感”“真实摄影感”“8K 超清质感”可以作为所需效果的总括，再补充对应的可见特征 |
| 光线与色彩 | 光从哪里来，主辅光或冷暖关系，高光和暗部保留什么，人物与环境如何处在同一光照下；外观参考的棚拍布光不自动照搬到剧情场景 |
| 材质与清晰度 | 挑当前画面能看见的细节，如织物纹理、金属反光、纸面纤维、皮肤自然纹理；主体清晰、景深和背景层次与镜头目的相容 |
| 空间与连续性 | 人物数量与身份、空间锚点、相对站位、道具形态和持物关系稳定；换机位时保持世界中的关系与轴线依据 |
| 运动与物理 | 动作有重心、接触和受力，衣物及环境响应同一运动；连续运动的速度、方向和焦点变化有承接 |
| 声音与可见文字 | 分别选择对白、动作声、环境声和配乐；分别说明字幕、产品原有文字、招牌或新增文字是否保留，必要时限定例外 |

“8K”“4K”“HDR”“24fps”、镜头或引擎名出现在正文中，只表达所选视觉意图，不能证明真实输出规格或某种渲染流程已启用。实际分辨率、帧率、画幅、时长与音频开关按当前模型支持的参数设置、保存和回读。不要为了写“8K”擅自提高生成规格。

保留用户需要的高清、真实感或电影质感，不因这些词通用就全部删除；合并重复后，用有关细节支撑。写实可以保留自然皮肤纹理与接触阴影，毛毡可以突出纤维和柔软体积，三维动画可以保留有意设计的高光与形变。不要把写实、浅景深、手持、禁 CG、无字幕或无配乐变成所有题材的默认要求。

## 写成可拍摄的过程

围绕当前镜头需要的信息组织正文，不强制给每条短提示词填满所有栏目。

| 描述对象 | 应写清的内容 |
| --- | --- |
| 主体与空间 | 谁或什么位于哪里，前中后景、身体朝向、视线目标、道具由谁持有；多人交互时说清动作对象 |
| 动作过程 | 起始姿态、触发动作、接触或受力、运动方向与速度变化、最终姿态；主体运动与摄影机运动分开写 |
| 表演与情绪 | 用目光、眉眼、嘴角、呼吸、肩背和手指等可见变化呈现心理；微表情服务当前事件 |
| 镜头与焦点 | 需要看见什么，使用何种景别和观察角度，镜头何时移动或切换，焦点最终落在哪里 |
| 光影与质感 | 光源方向、冷暖与明暗关系、与主体有关的材料或风格特征；人物、环境与特效处于一致光照中 |
| 时间与声音 | 动作与停顿的顺序，切点或衔接状态；对白说话者、画内外关系、语气及必要的环境声与动作声 |

动作按发生顺序写。一条动作链尽量围绕一个明确目标；重点动作给足准备、发生和结果的可见过程。需要细节时写相关材料怎样响应运动，例如衣摆滞后摆动、蒸汽上升后散开、脚落地后身体重心稳定。

运镜应帮助观众看清动作、获得信息或感受关系变化。单镜头只保留相容的运动顺序；复杂运动写清先后，不同时堆叠推、拉、摇、移、环绕和变焦。

情绪变化要有触发和递进。例如从看向门口、停住手部动作，到收紧嘴角，再转向对方。避免只写“情绪拉满”“极度震撼”“表现高级感”。

## 让参考跟随具体画面

先确认每份素材对应谁、什么物件或空间，以及本次采用的属性。对应表可以帮助读者理解，但不能替代正文中的引用。以下 `@图片1`、`@视频1`、`@音频1` 仅示意写法，实际标签须与当前输入绑定一致。

| 使用位置 | 引用怎样落入正文 |
| --- | --- |
| 新镜头、反打、切回或人物再次入画 | 在该处首次点明的人物旁重新引用，如“反打乙@图片2，乙抬眼看向甲@图片1” |
| 过肩、多人互动或焦点换人 | 明确前景肩背属于谁、焦点落在谁、动作指向谁；避免连续用“他”代替不同人物 |
| 取物、交接、接触或再次展示道具 | 将人物与道具分别引用在对应动作旁，如“甲@图片1接稳钥匙@图片3后，乙@图片2才松手” |
| 换角度或需要特定构图 | 在对应镜头旁引用该视角，说明只采用空间布局或观察方向，不把正面图和反拍图当成两个地点 |
| 复用视频中的动作或运镜 | 写清仅采用哪段动作、节奏或摄影机路径；人物、产品外形和原片声音是否采用分别说明 |
| 角色开口、旁白或声音跨切镜 | 绑定明确发声者，必要时在对应台词旁重引音频；说明取音色、节奏还是原音，实际台词另按本段原句执行 |

重复的目的是在新的画面语境中消除歧义。同一镜头、同一动作链内指代清楚时可以自然使用称呼或代词，不给每个词都加引用，不重复整段外观和禁令。角色在新镜头出现时，应重新判断该处是否需要引用，不能把开头已声明当作后文永久省略的理由。

同一角色的全身图、脸部图、侧面图是同一身份的不同依据，不生成额外人物。同一产品的多视图也不意味着多件产品。只将本镜实际需要的素材作为参考，声音参考不承担外观任务，图片不能充当音色依据。多份参考存在差异时，明确各自负责的属性和本次采用哪一项；无法确定的冲突先核对来源。

角色身份与当下状态分开写。外观图提供身份依据，本段仍要交代站位、朝向、持物及前镜遗留状态；同一引用不等于动作已经衔接。将“伸手、接稳、松手、物件留在哪只手”等可见过程写在一起。

在 OUO 画布保存时，在每个实际位置用 `set_prompt.parts` 交错传文字与真实 `reference`；同一来源在后面的镜头再次使用，就再次插入该来源的引用片段，复用节点而非复制素材。仅键入普通 `@角色名`、手写序号或连接素材，均不能证明已有原生绑定。模型标签和媒体输入另按实时契约核验，不能把示例编号或画布标记直接套到模型请求。

## 片段内时间节拍

区分三个层次：成片中的剪辑顺序或集内时间、本次生成的实际总时长、这一片段内部的动作节拍。成片中的“30-45 秒”不直接成为一个 15 秒生成片段的内部计时；内部通常从 0 开始。

已知片段时长且有多个动作、表演转折、对白或信息揭示时，默认用连续秒段分配节拍，即使是一镜到底也适用。每段写清谁在何处做什么、镜头或焦点怎样承接、哪些声音在何时发生、段末留下什么状态。有参考时在对应动作、换主体和关键交互处就地引用。不要只在开头写总时长、后面全用无时间的剧情概述。

例如，一个已确认 8 秒的连续镜头可以写成“0-2 秒看见线索，2-5 秒停手并抬眼，5-8 秒说出短句并保留反应”。时间段表示动作进程；只有明确写“切至”或相应剪辑指令时才表示切镜。机位、移动路径和场景连续时，不因出现多个时间段而新增镜头。

同一条主画面时间线从 0 覆盖到已选总时长，检查倒序、空缺、意外重叠和正文与参数时长不一致。并行的动作、对白或环境声可以重叠，需说明各自归属；同一段不要因分列声画而重复计入总时长。逐段时长、累计时间和模型结构化分段只选需要的表达，编译时再核对真实契约，不自行发明 `multi_prompt` 字段。

给动作的准备、接触、反应、台词停顿与结尾收势留时间。按实际原句朗读估算对白，长句不能靠“正常语速”“精确完成”塞进过短窗口。内容过密时减少次要动作、调整切点，或说明需要延长、拆段；不默默删改必须保留的台词。结尾是继续运动、停留观察还是供下段承接，由本段目的决定。

未知时长时先写相对先后与停顿，不编造秒数；已知时长但只有一个简单持续动作时可直接描述其覆盖全段。用户提供的格式优先，声画表或模型结构化格式也可清楚表达这些节拍。时间标记是导演意图，不承诺精确帧数或实际效果。

## 对白与声音层次

- 多镜头按情节节点切分，各镜头提供新的信息或表演变化；切点有动作、视线、声音或遮挡等承接依据。单一动作不需要强拆多个镜头。
- 对白原句与实际发生的镜头或时间段有明确对应，写清说话者和语气。默认可与说话动作及必要的听者反应连贯描述；用户选择的声画表或模型结构化格式只要对应清楚，同样有效。分清对白、画外音、内心独白和屏幕文字；有台词不等于要生成字幕。
- 分镜记录可以分别保存动作和对白；按所选写法让实际原句、动作和画面对应，避免只有“某人说原句、另一人接话”的摘要而无法确定声画关系。分列本身不是问题。台词跨切镜时明确说话者、延续到哪个镜头以及此时画面中的反应。
- 声音可先于画面引出事件，也可在切镜后延续；写清声音来源和远近变化。配乐与环境声分别处理，是否使用配乐由当前任务决定。
- 对白、动作同步音、环境底声与配乐分层安排。贯穿环境声可统一写，关键碰响、脚步或呼吸跟随发生的动作；无配乐不等于无声，无对白也不等于没有环境声。只写当前任务需要的声音。
- 不承诺仅凭提示词能保证精确帧数、口型、逐帧一致性或具体生成效果。只有任务需要且已确认目标平台能力时才做专用参数适配。

## 负面约束与保留项

先写希望出现的状态，再针对本镜易错处补充“不要什么”或“保持什么”。负面约束可以有独立小段，也可贴近对应动作；选择能消除当前歧义的项目，不按词表长度判断质量。

| 易错处 | 约束方向 |
| --- | --- |
| 身份与数量 | 同一角色不换脸，多视图不增加角色或产品数量，道具不复制、不无故换手 |
| 动作与空间 | 保持运动方向、接触关系和路径，不瞬移、不穿模；只在需要连续拍摄时限制切镜，按剧情决定是否越轴 |
| 时序与表演 | 不跳过关键接触或反应，不把尚未知道的信息提前表演，不在动作完成后重播 |
| 材质与画面缺陷 | 针对主体避免轮廓扭曲、纹理闪烁、曝光跳变或不合所选媒介的质感；人体细节约束仅在相关部位可见时使用 |
| 文字、声音与编辑范围 | 限制新增字幕、水印、额外台词或无关配乐，明确原有产品标识等保留例外；局部编辑写清哪些区域与属性保留 |

正负描述共同核对：手部操作不能同时要求“无手”，展示原有标识不能同时“禁止任何文字”，三维动画不能套“禁止 CG”，换背景并重打光不能同时锁死原背景与全部照明。仅禁用新叠加字幕时就这样限定，不扩大成删除场景和产品原有文字。复杂冲突无法确定取舍时按用户意图核对。

自然语言里的“不要”“禁止”“保持”可作为正文约束；独立 `negative_prompt` 参数只在当前模型契约明确支持时使用，字段格式与可用性另行核验。不能从别人的请求出现该字段就推断本次模型支持，也不把负面词误当成希望生成的内容。不要把“字体不透明度为 0%”、自造参考权重等未确认写法当作可靠控制能力。

## 改写与压缩

改写已有提示词时，先提取有效事实与约束，再重新组织。合并重复画质词、整段复述的“导演描述＋最终 Prompt”、反复出现的禁令与冗余模板头，保留其中独有的视觉、声音和约束信息。全局要求写一次，局部差异写在相应段落；不要把有效的高清、真实感要求或切镜、重入画、交互处的重复引用当作套话删除。

把抽象或有冲突的表述改成明确作用域。例如：

| 原表述 | 描写方向 |
| --- | --- |
| “眼神悲伤，情绪拉满” | 视线停在空座位上，眼眶发红，嘴角微微收紧，抬手前短暂停顿 |
| “动作真实自然” | 说清手接触道具的位置、道具移动方向、身体怎样随重心调整 |
| “运镜流畅、很有冲击力” | 指定从哪里起幅、沿什么方向移动、何时停住以及要揭示的信息 |
| “物体不动，光效要动” | 锁定物体位置与形态，描述表面光带的流动路径和背景粒子运动 |
| “全程固定镜头，又缓慢推近” | 依据明确意图选择锁定构图，或稳定推进；不能把稳定拍摄等同于完全固定 |
| “适配某引擎、8K、顶级大片”反复出现 | 保留需要的风格，补足具体的照明、材质、空间和动作描述 |

约束写到对应对象和阶段。针对本段最容易出错的地方给出必要限制，例如某角色始终只持有一个杯子、仅编辑天空、完成开门后保持门开启。不要附加与本段无关的长串负面词。

检查时长、角色指代与循环闭合，修正可确定的冲突；关键意图不明时简短澄清。

## 交付

跟随用户指定格式。未指定时，给出简短全局视觉与必要通用要求，再按动作进程写正文；已知时长且有多个节拍时标注连续时间段，一镜到底也适用，多镜头另明确切点。简单持续动作可用一段可直接使用的文字。必要负面约束在结尾或对应动作旁交代，不强制填满栏目。正文不夹带分析、自评、教学文字、替代方案或未填写的模板项。

写完核对：

- 主体、事件、动作顺序和画面重点清楚，人物称呼具体且稳定。
- 逐镜核对引用落点、主体、用途和真实来源；新镜头、反打、重新入画与关键交互处没有仅靠开头映射或含混代词。重复引用仍指向同一准确素材，前后没有错号、串人物或把外观图当音色。
- 主体称呼一致，接触关系和持物关系清楚；同一机位下空间关系不无故跳变，换机位时视线和运动方向有连续依据。
- 区分主体静止、机位锁定、背景静止、焦点变化和特效运动，约束不会互相误伤。
- 景别能够展示指定动作；全身动作不被纯面部特写遮掉，重要动作不在镜头范围之外完成。
- 锁定构图与运镜、单镜头与切镜、可见文字与禁字要求、声音与静音要求没有冲突；分段的例外明确。
- 时间可容纳内容；续接继承结束状态，循环闭合位置、姿态及运动相位；编辑的修改范围明确。
- 已知时长的多节拍片段有可核对的时间分配，主画面时间线覆盖 0 到总时长，正文与实际参数一致；没有把时间段误当成切镜，也没有给未知时长编造秒数。
- 全局媒介、画质、光线、材质与场景相容；风格词有具体画面依据，正文规格词没有被当作真实输出参数。
