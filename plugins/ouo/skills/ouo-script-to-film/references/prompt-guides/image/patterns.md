# 分任务写作

先选主内容，再叠加适用的成图形式或编辑方式。主内容决定信息顺序，成图形式决定分区、数量与连续性。

## 人物与角色

角色单图可以按“身份与外轮廓 → 辨识细节 → 服饰部件 → 站姿、取景与受光”组织。优先写两三个能让角色被认出的特征，如方框眼镜、短发外轮廓、夹克肩线；近景再补眉眼、肤质与表情细节。非人角色优先交代种类、体型、辨识色块、附肢和姿态。

先固定人物数量、区别与相对位置，再写体态、服装、姿势和可见表情。两名角色要有稳定称呼，避免“他”“另一个人”在多句中互换。

全身图需要头顶至鞋底完整入画，手部操作需要看见接触点，面部特写则集中于可见微表情。不要要求纯脸部特写同时展示完整站姿、鞋底和场景全貌。

角色经历和性格需要转成当前画面中的衣着、姿态或表情线索；保留用户指定的身份，不把整段背景故事原样当作外观描写。

## 角色三视图与设定板

先明确是脸部还是全身，是标准转面还是含表情、配饰、色卡的综合设定板。写清每个区域的用途；不要把完整设定板模板加到只要求三视图的任务中。

把“参考资料含有哪些视图”与“本次输出哪些视图”分开。设定板也可用于场景或道具。场景板交代主视图、辅助机位和重点区域，道具板把盘面、厚度、接缝等结构分配给能看清相应细节的视角。

短剧共享角色标准图默认是一张 16:9 横幅的纯白底全身三视图，从左到右为正面、人物左侧面、背面；角色变体沿用此规格并保持母图身份。用户明确的其他规格优先，普通头像、肖像或分镜不自动改为三视图。

短剧标准图采用中性站姿、自然垂臂、平视和均匀柔光，视图之间留出间隔，头顶至鞋底完整入画。纯白背景不带彩色底、渐变、环境、道具布景或装饰边框；主体保留合理的体积明暗。不额外添加头像、表情小样、色卡或文字标签，除非用户明确要求。

标准全身三视图通常需要正面、明确的一侧和背面。各视图的身份、身高、体型、服装结构、配色、鞋子和配饰一致，保持同一站姿逻辑、观察高度和统一光照。

对齐脚底与整体尺度，避免透视夸张；不同视角按真实结构呈现遮挡与轮廓。不能要求正面、侧面和背面同时显示完全相同的面部细节，也不能将一个角色的三个视图描述成三个不同的人。

脸部转面写清角度与裁切范围。额外表情、服装拆解和标注文字仅在用户要求时添加。不可见结构可以按已有设计合理补全，但不宣称看到了未提供的细节。

## 场景、建筑与空镜

可按“地点、年代与时间 → 观察位置、入口和通道 → 地标和前中后景 → 光色、天气与材质”组织。空间反复出现在剧情中时，给出能跨镜头定位的墙、门窗、道路或地貌锚点。附属道具用来交代使用历史、相对尺度或动线。

角度要与空间信息相容：垂直俯视侧重平面关系，低机位突出高度，洞外朝内与洞内朝外会形成不同遮挡和光线。不要把这些观察位置混写成同一机位。

空镜中的天气、痕迹和陈设也可以表达情绪。风雨写成雨丝方向、湿痕、雾的遮挡和被压低的枝叶等可见状态；不需要声音来补充画面。

用户明确需要全景图时，区分普通宽视野取景与用于环视的展开图；不要仅看到“全景”就自动添加球面投影要求。

## 产品、食物与器物

短剧共享道具标准图默认为纯白背景、1:1 方图，单件物品或剧本明确的一组物件完整居中，四周留白，选择能看清轮廓与关键结构的角度。均匀中性柔光表现真实材质，不带人物、手持展示、桌面、剧情环境或装饰，不自动添加多视图、拆解图及额外文案；保留已确认的必要标识。商业产品图或剧情静帧沿用自身要求，用户明确的其他规格优先。

可按“什么物件、几件、做什么用 → 整体外形、比例和部件连接 → 展示角度和摆放 → 材质、磨损与受光”组织。需要看清背部接口或侧面厚度时，把对应面安排在可见角度。拉丝金属有方向性反射，磨砂表面高光更宽，透明杯壁需要合理透光和轮廓。

产品结构、文字和图案有既定设计时按要求保留，不新增按钮、卡扣、品牌或包装文案。倒影与分离配件不应被误描述成第二件产品。

食品或液体画面选一个关键瞬间，例如细茶流连着壶口与杯沿、切面露出内层结构。不要让单张图同时展示完整操作流程。

商业画面先安排主体和留白，再放装饰，避免背景道具遮挡结构、标签或主要卖点。

## 叙事单帧

可按“关键瞬间与景别 → 各人站位、朝向和视线 → 手与道具或环境的接触 → 前后景、焦点与受光”组织。一句交代画面正在被看到的动作状态，例如“她停在门槛内侧，按在门框上的右手还没有松开”。剧情时间、情绪与因果通过门的开合、人物所处位置、表情和持物状态体现。

同一画面有角色、道具和场景时，先保住叙事关系，再补本帧可见的辨识特征。背景细节的密度和清晰度跟着视线重点走。

## 海报、包装与标题主视觉

明确主视觉与标题的主次、阅读顺序、可用文案和留白位置。文案准确性包括中文标点、英文大小写与数字；不要以“漂亮字体”代替具体文字。

字体描述可以落到字重、笔画、材质、排列方向与空间关系。若标题本身是画面主体，背景人物和装饰应降低对比与细节密度。

画布比例、包装展开尺寸和局部分区比例分别说明。原包装的结构和印刷需要保持时，不因“重新设计背景”而擅自改写包装内容。

## 多格图片与故事板

写明是一张合成图还是若干独立图片，以及行列、格数、阅读顺序和各格内容。整体画幅与单格画幅分别表达，不能把二者混为同一约束。

每格选择一个可见状态，组合成清楚的事件或视角变化。可以改变景别与角度，但角色身份、服装、道具、环境和光线有连续依据。

不要为了镜头丰富而在连续动作中无故改变人物所在位置。必要的编号、字幕和对白文字明确列出；没有要求时不额外添加。

## 局部编辑、去除与扩图

局部编辑用“目标区域、目标状态、保留范围”组织。去除物体时补齐被遮挡的背景，匹配周围透视、纹理、景深与光照；不把标记框、涂抹痕迹或选区边界绘入成图。

换色保留材质与明暗，改表情保留身份，改背景明确是否保留主体受光；不能同时要求改变整体照明与所有受光完全不变。

扩图写清扩展方向、成图比例和原有内容保留方式。新区域自然接续道路、墙面、植被、天际线与光影，避免复制原主体、增加无关人物或在边缘保留空白。

换机位先写新的观察位置、朝向、景别和裁切，列出仍可辨认的地标与结构。背景被新裁掉、遮挡改变或透视随相机移动时，按新视角描述。修复先指明要去掉的损伤，例如某处压缩方块、重影或边缘毛刺，再写要保留的真实纹理、颜色及原始光影。

## 风格转换

先确定要保留的结构和目标风格怎样改变表现：体块是否概括、边缘是否柔化、纹理是否减少、笔触是否显露、色彩是否压缩。

“改成动画风”不等于涂一层滤镜；应具体说明哪些形状、材质和色块需要重新组织。用户只要求风格转换时，主体数量、服装、位置和构图不应随之变化。

根据目标风格选择材质表现，不默认把所有表面处理成全哑光或零反射。
