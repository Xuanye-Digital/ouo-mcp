# 图片提示词写作

把用户想要的图像写成可观察、构图明确、约束相容的画面。重点是主体、位置、姿态、光影、材质、风格与版式，不用长度、器材型号或重复画质标签代替描述。

提示词正文不包含素材引用标记或绑定说明。

新编写或获准改写图片提示词前，默认读取并应用本章。仅搭工作流或只交付提示词同样适用，复用本次已读内容。用户本次要求、提供的提示词与指定格式优先，用户明确指定其他写作 Skill 或写法时采用其选择。仅保存或直接使用用户原文时保留正文。审阅关注用户目标、所选写作依据、事实与约束一致性及模型可执行性。

## 先按内容与任务分类

先判断成图的主内容，再确认交付形式和是否编辑已有图。按这两步读取 `section=patterns` 的相关主内容和任务章节。分类用于选择描述重点，用户要成稿时直接给提示词。

| 主内容 | 先写什么 |
| --- | --- |
| 场景、建筑与空镜 | 观察位置、空间骨架、可复用的地标和前中后景 |
| 人物与角色 | 身份、轮廓和最有辨识度的外观，再写服装、姿态与景别 |
| 道具、产品与食物 | 件数、用途、形状、结构和展示角度，再写关键材质 |
| 叙事单帧 | 此刻发生什么、谁在什么位置、视线和接触关系，再写镜头及氛围 |
| 图文与版式 | 画面用途、准确文案、视觉主次与可读位置 |

交付形式包括单图、多视图或设定板、分格或多张图。编辑任务再明确是局部增删替换、换机位或重构图、风格转换、修复还是扩图。分类看用户这次要得到的结果。参考三视图生成一张俯拍剧照，走叙事单帧与单图；修改三视图的衣领，走人物、多视图与局部编辑。只改一项时可从目标区域和变化直接起笔。

保留用户已给定的主体身份、数量、外观、场景、姿态、风格、画幅、文字原句和修改范围。独立提示词任务没有指定的比例、分辨率、焦段、背景颜色、人物数量或禁字要求，不套用固定默认值；已有明确素材规格的工作流按其规格编写，用户明确要求优先。

### 短剧共享素材默认规格

短剧工作流新建或明确改写共享参考图时，角色图默认纯白背景、16:9 横幅，一张图内从左到右排列同一角色的正面、人物左侧面、背面全身三视图；道具图默认纯白背景、1:1 方图，完整居中展示单件物品或剧本明确的一组物件。三视图是同一角色的三个角度，输出一张，不是三个人或三张图。白底是均匀纯白，不是浅灰、米色、彩色渐变或剧情环境；柔和中性光只用于表现主体结构与材质。

素材图比例独立于成片或视频的 `preferences.aspectRatio`。构图可在正文中说明，但准备生成还须读取实时模型 schema，将准确比例显式写入实际支持的参数字段，保存后独立回读；只写“16:9”、只改变节点显示尺寸或沿用模型默认值都不证明实际比例已设置。模型不支持所需比例时说明限制并按当前授权选择可用方案，不静默改比例。场景图、静态分镜和其他图片按各自需求编写；已有准确上传、库存或已确认素材优先复用，不因格式差异自动重做。

区分成图数量与图内数量：“一张三视图设定稿”是一张图内的三个视图，不是三个角色或三个文件；“一张九宫格”需要明确行列和阅读顺序。

已有要求出现冲突时，先核对作用对象与区域。全身主视图和脸部特写可以分区共存；同一区域同时要求完整全身与仅面部、同一画布同时要求方形与横幅，则需要根据明确意图消除冲突。关键目标无法判断时再做简短澄清。

## 描述一幅能看见的画面

根据当前图像需要组织信息，不要求每条短指令都填满所有维度。

| 维度 | 需要明确的内容 |
| --- | --- |
| 主体 | 是谁或什么、数量、主要外形、服装或部件、需要保留的身份特征 |
| 姿态与表情 | 可见的身体朝向、视线、持物和接触位置、表情细节、当前动作阶段 |
| 构图与空间 | 主体位于哪里、占画面多少、前中后景、相对大小、遮挡关系和留白区域 |
| 观察角度 | 景别、观察高度、俯仰角、透视及裁切范围；多视图中各角度分别展示什么 |
| 光影与材质 | 光源方向、软硬、冷暖、阴影走向，以及材质如何响应这些光线 |
| 风格与色彩 | 轮廓、笔触、体积、纹理密度、主色与点缀色如何共同形成目标风格 |
| 版式与文字 | 图内分区、视觉层级、文字原句、位置、字号关系和允许出现的标签 |

用明确主体称呼连接描述。多人或多物时写清谁在左前、谁在右后，哪只手握住哪件物品，何物遮住何物；区分画面左右与人物自身左右。

图像中的动作是一种可见状态。例如“倒茶”可以写成壶口下方连着一束细茶流、杯中液面已有水纹。单幅图不同时承载拿起、倒空、放回等完整过程。分格任务则把不同阶段分到不同格。

运镜、播放时长、声音和剪辑节奏不能直接充当静态画面信息。需要改写视频式输入时，提取用户要表现的关键瞬间、视角与构图；没有要求分格时，不擅自改成故事板。

## 把抽象评价换成可见线索

| 宽泛或冗余表述 | 更具体的写法 |
| --- | --- |
| 高级感、电影感 | 指出视觉中心、背景信息密度、色彩关系、光比和空间层次 |
| 角色焦急、情绪强烈 | 眉间收紧、嘴唇微张、视线锁定门口、手指紧握衣角 |
| 材质真实、超高清 | 描述相关的织物纹理、金属拉丝方向、粗糙度、透光和接触阴影 |
| 空间很有纵深 | 前景遮挡、中景主体、远景明暗与清晰度衰减有明确关系 |
| 镜头拉远一点 | 成图改为更宽的取景，说明新入画的身体部位或环境；扩图时另限定保留区域 |
| 哑光、无油腻感 | 表面以柔和宽阔的明暗过渡为主，收敛刺眼小高光，保留体积与必要纹理 |

风格应影响形状、边缘、色块、纹理与材料表达。水墨、手绘、写实摄影、3D 动画可以有用户指定的混合方式，但不能只把不同风格标签堆在一起。

## 按需补充画质与反面约束

先写完整的画面目标，再从下面挑当前画面需要的内容。补充项可直接写进所属段落。共享光色、同一角色或材质等要求适用于全图时，集中说明一次。

### 常用补充项

| 需要强化的内容 | 可直接改写使用的描述 | 适用情况 |
| --- | --- | --- |
| 对焦和景深 | 清晰对焦在人物双眼与面部，远处灯点柔和虚化 | 人像突出表情，背景无需读清。多视图、包装文字或场景勘察需要多个位置清楚时，按实际焦点范围写 |
| 光色和曝光 | 窗边亮处保留木纹，桌下暗处仍可辨认轮廓，冷白窗光与暖色台灯各有范围 | 有高反差、逆光或两种光源 |
| 材质和细节层次 | 保留衣领纤维和袖口磨白，皮肤保留细微纹理，远处墙面只留大面明暗 | 需要区分哪些地方细、哪些地方简化 |
| 表面、边缘和接触 | 金属窄高光随边缘转折，物件下方有贴合桌面的短阴影 | 道具或合成物需要与环境接合 |
| 干净和留白 | 上方留整块低对比墙面，柜台只摆一只杯与一张折叠餐巾 | 需要文案位、干净背景或限定道具数量 |
| 一致性 | 各格保持同一发型、外套和手提包，窗光从画面左侧照入 | 多视图、分格、系列图或多参考合成，机位改变时按真实空间关系描述光源 |

“清晰、低饱和、浅景深、胶片颗粒”各自控制不同画面属性。已有足够明确的要求可以保留一次简短全局方向。分辨率、画幅、张数按用户要求及实际参数处理，画质词本身无法设置这些参数。

### 按失败风险选反面提示

从用户明示的禁项、参考图中已有的问题和该画面最容易出现的错误出发。先给模型可画的目标，有必要时再明确应排除的结果。用户定义的禁项完整保留。

| 类型 | 容易偏离的结果 | 定向写法 |
| --- | --- | --- |
| 场景 | 错加通道、倒置地标、前后景光向不合 | 石阶只从左前方通向亭门，两侧为完整石栏，湖面只在亭后出现 |
| 人物与持物 | 脸型漂移、磨皮、手和物体穿插、非预期裁切 | 保留原颌线与自然肤质，右手拇指扣在提手内侧，其余手指包住提手，头顶到鞋底完整入画 |
| 道具与产品 | 增加零件、轮廓变形、镜像冒充另一件、标签被重写 | 一只杯身配一只独立杯盖，螺纹仅位于杯口内侧，保留原品牌拼写，不新增开关 |
| 叙事单帧 | 视线错位、遮挡关键动作、站位反转、背景抢焦 | 门口人物望向右前方桌边的人，两人之间保留可见通道，握门框的手完整入画 |
| 多视图或分格 | 同角度重复、身份配饰不一致、格数或出图数错 | 一张图按左中右排列正面、左侧面和背面，脚底对齐，同一件外套和同一副眼镜随视角合理遮挡 |
| 图文与版式 | 多余字样、水印、错字、原标识丢失 | 标题准确为“雨夜来信”，上方居中，保留瓶身原有标识，不添加额外文案或水印 |
| 编辑与修复 | 误改未选区域、纹理被抹掉、边缘残留编辑标记 | 只修复玻璃边缘的压缩重影，保留玻璃反射和原曝光，标记框只用于定位 |

未指定模型时，排除项可紧邻相关对象写入自然语言。准备调用模型时，只有实际接口确认支持独立负向字段或专用语法，且本次确实需要，才按其契约填入。参数名、写法和支持情况以实际模型及接口为准。可以用“保留包装原有文字，背景留空”表达画面目标，避免把全局“无字”同时施加在包装上。

常见的长串反面词会把不同任务的要求混在一起。复核诸如禁止文字与指定标题、禁止颗粒与胶片质感、全画面锐利与浅景深等组合，按对象和区域判断哪些要求能够并存。

## 编辑时限定修改范围

先说明改哪里、改成什么，再写有必要保留的内容。保留项服务当前任务，不自动把所有属性锁死：改表情仍可保留身份和服装，改姿势则不能同时要求姿势完全不变。

替换或新增内容与保留部分的透视、尺度、遮挡、光线和接触阴影相容。局部换色通常保留材质纹理与原有明暗；整体改成黄昏则需要同步描述受光和色调变化。

扩图、重裁切与改变观察角度是不同操作。扩图优先延续边缘空间，不把原主体重画一遍；新的观察角度会改变遮挡关系，不能同时要求所有像素位置不变。未看到原图细节时，不臆造其外观作为已知事实。

## 文字与版面

文字需要出现时，用引号给出准确内容，保留标点、大小写、数字和专有名称；说明标题、正文、标签的层级与位置。没有文案时不擅自编造品牌、价格、宣传语或人物设定说明。

“无额外文字”可以与保留产品原有标识共存；“画面不出现任何文字”则与可读标题冲突。按用户的实际范围表达，不附加全局禁字模板。

主体与文字共享空间时，给出具体分区和留白。多视图对齐的是合理的角色尺度和基线，不要求不同角度的所有轮廓、服装褶皱与可见部件完全重合。

## 改写与交付

先提取有效事实，再按成图逻辑重组。删去重复画质词、无内容的操作尾句、未填模板、与图片无关的声音或播放要求，以及重复复述同一目标的段落。约束写到对象和范围，不附加与本图无关的长串负面词。

默认只输出可直接使用的描述正文。单图给一段或少量清晰段落，多格或多区按位置组织。用户要求结构化格式时遵循其格式。正文不混入分析、自评、教学解释或未填写的占位项。

交付前核对：

- 主体、数量、姿态、持物与空间关系明确，景别能够容纳要展示的内容。
- 单幅图聚焦可见状态；多格任务的格数、顺序、角色与道具连续性成立。
- 画布比例、分区比例、输出张数与视图数没有混淆。
- 光源、阴影、材质和风格相容，保留必要细节，不把干净等同于抹掉一切纹理。
- 修改范围与保留条款不互相冲突，扩图或换视角的描述符合目标操作。
- 文字原句准确，标题、标识与禁字要求没有冲突；不存在残留模板或重复禁令。

需要成品示范时，通过 `get_image_prompt_guide(params={"section":"examples"})` 读取。
