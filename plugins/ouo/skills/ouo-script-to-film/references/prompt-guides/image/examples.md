# 描述示例

例中的画幅、风格、角色和文字要求只属于该案例，不是默认参数。代码块中的文本是提示词正文。

## 1. 两名角色：数量、差异与站姿

**输入条件**：两名装备齐整的成年警察，一高一矮，高者偏瘦，矮者有小肚子，展示全身。

```text
两名成年警察并排站在浅灰背景前，全身从头顶到鞋底完整入画。画面左侧的警察较高、身形清瘦，右侧的警察明显较矮，腰腹略圆，两人肩线和头顶高度体现出清楚的身高差。

两人均穿整洁的深色警服，腰带与执勤装备佩戴完整，服装版型贴合各自体型。身体朝前，双臂自然下垂，双脚稳定落地，不互相遮挡。采用平视观察角度和柔和均匀光线，保留衣料褶皱、装备轮廓与脚下接触阴影。
```

## 2. 场景：用布局与材料建立空间

**输入条件**：雨天的流浪动物救助基地兼废品回收院，3D 动画场景，低反光材质，无人物。

```text
细雨中的城郊小院兼作动物救助基地与废品回收场，画面内没有人物。平视广角构图，中央留出一条通向院后小屋的狭窄通道；左侧整齐堆着压好的纸板捆与旧塑料筐，右侧是一排低矮空犬舍，铁丝网与波纹棚顶轮廓清楚，棚顶搭着褪色防水布。

前景散放少量掉漆食盆，盆底可见薄薄积水。细雨在较暗背景前呈淡灰短线，地面以深浅湿痕表现潮湿，不出现大面积镜面倒影。阴天漫射光让整体明暗柔和，纸板纤维、旧木和锈色金属采用概括的低反光动画材质，院子破旧但有秩序，通道保持畅通。
```

## 3. 三视图：一张画布内保持设计一致

**输入条件**：一张 16:9 全身三视图，正面、人物左侧面、背面，纯白背景；服装为白衬衣、咖啡色短夹克、黑色直筒长裤与深灰运动鞋。

```text
一张横向 16:9 的角色全身三视图设定稿，纯白背景。从左到右等距排列同一角色的正面、人物左侧面和背面，头顶高度、脚底基线与整体尺度统一，每个视图均完整展示头部至鞋底。

角色穿白色衬衣，衣摆塞入裤腰，外搭咖啡色短夹克，配黑色直筒长裤和深灰运动鞋。三视图保留同一脸部身份、发型、身高、体型、服装结构、配色与配饰，各部件随观察角度呈现合理遮挡。统一中性站姿、自然垂臂和柔和光照，避免夸张透视。只展示这三个全身视图，不额外加入头像、表情小样、文字标签或装饰。
```

## 4. 产品：区分材质与配件

**输入条件**：奶白色不锈钢保温杯商业静物，9:16，杯盖分离，仅一个产品，无额外文案。

```text
9:16 竖幅商业静物照片。一个奶白色不锈钢保温杯直立在木质露营桌面上，杯身位于画面中下部，杯口开启；分离的杯盖平放在杯身右前方，尺寸与杯口匹配，二者之间保留清楚间隔。

柔和日光从左上方照入，奶白杯身呈细腻哑光表面，银色金属杯口保留克制的窄高光，杯盖磨砂质感与金属边缘有明确区别。杯底和杯盖下方都有贴合桌面的柔和接触阴影。焦点覆盖杯口与主要结构，远处露营环境轻微虚化，画面上方留出干净空间。保留既定产品结构与标识，不新增零件、第二个杯子或额外文案。
```

## 5. 局部编辑：改表情与去发光，保留其他内容

**输入条件**：人物改为焦急表情，去掉背景油灯与帐篷的发光效果，保留物体与原构图。

```text
只修改人物表情和画面左侧背景中的发光效果。人物眉间收紧，嘴唇微张，额头出现少量汗珠，视线保持原方向，呈现焦急状态；保留原有脸部身份、发型、服装、身体姿势和持物关系。

左侧背景中的油灯与帐篷仍位于原位置，保持原来的虚化程度，但去掉它们的自发光、亮窗与周围光晕，不删除油灯或帐篷本体。其余构图、主体受光、色调与场景细节保持不变。
```

## 6. 扩图：延续已有空间

**输入条件**：原图为雨后森林山路，中景站着一名男子；向左右扩成 16:9，原有内容不变，不新增人车。

```text
将原图向左右两侧扩展为 16:9 横幅，原有区域的男子、服装、姿势、道路与树木保持不变，不移动或缩放原主体。

左右新增区域自然延续已有山路走向、林木疏密与雨后雾气层次，边缘树干、地面湿痕和远处植被的透视与原图衔接。沿用原有光线方向、低饱和色调、景深与细节密度，新增区域铺满成图，不留白边，不增加人物、车辆或重复的男子。
```

## 7. 标题主视觉：准确文字与阅读层级

**输入条件**：电影片名“封箱·夜奔”，北方旧戏台、风雪夜色和木雕质感，仅出现片名。

```text
电影片名主视觉，文字准确为“封箱·夜奔”，居中突出，四字与中间圆点清楚可辨。标题如一块厚重旧木匾，字形结合浮雕与深雕，深褐木质表面保留刀痕、暗红戏漆和少量磨损金箔，凹槽中积着薄雪。

一支长枪从标题右侧斜穿边缘，附近点缀一对枣木梆子，避免遮挡笔画。背景是风雪中的北方乡村旧戏台，昏黄马灯只照亮局部台板，持枪武生以较低对比的侧影出现，不抢过标题。近景少量雪片、中景木雕标题、远景戏台形成层次，冷蓝灰夜色与暖黄灯火、暗红漆色相互呼应。除片名外不添加其他文字。
```

## 8. 水墨：把风格落到轮廓与色块

**输入条件**：森林中的小池塘，大全景，二维水墨手绘，无人物、文字或台阶。

```text
森林小池塘的大全景，前景是几块高低错落的岸石，中景水面被树木围合，远处林木以淡墨层次逐渐隐去。池岸保持自然起伏，不出现人工台阶，画面没有人物和文字。

采用二维水墨手绘表现，主要树干与石块有清晰而不均匀的粗黑轮廓，枝叶以概括色块和可见笔触组织，减少细碎写实纹理。水面以大块留白和少量灰绿色淡染表现，纸张纹理与边缘轻微渗化可见，整体保持平面手绘感，不加塑料高光或立体游戏材质。
```

## 9. 九宫格：每格一个可见状态

**输入条件**：一张 3×3 九宫格，深夜雨中的便利店，女子捧着热牛奶独坐，不加编号或文字。

```text
一张 3×3 九宫格分镜图，按从左到右、从上到下阅读。全组保持同一名短发年轻女子、灰色外套、便利店靠窗座位与深夜小雨环境，冷白室内灯与窗外潮湿街道的微弱暖光形成统一色调，格间分隔细而简洁，不绘制编号、字幕或对白文字。

第一行：左格为雨中便利店外景，亮着的玻璃窗成为视觉中心；中格从店内展示女子独坐靠窗高脚凳的全身位置，桌前是一盒热牛奶和关东煮；右格为侧面中景，女子双手捧着牛奶，视线停在窗面。

第二行：左格为双手与牛奶盒近景，手指包住盒身；中格为女子面部近景，神情安静，牛奶口的少量热气位于画面下缘；右格为窗上雨滴特写，远处路灯化为柔和色点。

第三行：左格从女子肩后看向窗外，肩部形成前景遮挡；中格借玻璃反射呈现她的侧脸与室内灯带；右格退回较宽的室内景，女子仍在同一座位捧着牛奶，周围空座位与安静街道强化独处的氛围。
```

## 10. 道具资产的结构与使用痕迹

**输入条件**为短剧共享道具图，一只旧黄铜怀表，表盖合上，偏左有一道凹痕，链条完整可见。

```text
一张 1:1 方图。一只合盖的旧黄铜怀表居中摆放在均匀纯白背景前，表盖朝上，挂链从上方挂环绕到表身右侧，链尾也完整入画。略高于桌面的三分之四视角同时看见表盖、合缝和表壳厚度。表盖偏左的一处浅凹痕清晰可见，密集细划痕集中在盖缘，转轴处有薄薄的暗褐氧化色。左上方的柔光沿黄铜边缘掠过，表背和链节下方保留柔和的接触阴影。
```

## 11. 参考角色设定的叙事单帧

**输入条件**为依据已有角色三视图中的短发、深蓝围裙和浅色衬衣，写咖啡店门口的一张横幅剧照。店员正要关门，看见窗外还有客人。

```text
一张横幅中景剧照，从店内斜看入口。店员站在画面右侧门槛内，一手握住半掩的玻璃门，身体仍朝向门外，脸转向左前方的窗外。沿用角色设定中的短发外轮廓、深蓝围裙和浅色衬衣。窗外一名客人停在屋檐下，双手抱着合起的雨伞，隔着玻璃与店员对视。玻璃门框留在两人之间的画面空隙，握门的手和两人的视线关系清楚可见。店内暖光照亮店员的侧脸，窗外雨痕与街灯压在较暗背景里。
```
