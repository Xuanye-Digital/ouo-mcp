# 连续性与素材复用

## 身份和版本

角色身份与服装、伤势、发型等状态分离。场景身份与布置、损坏、门窗状态分离。道具身份与持有者、位置、完整性分离。版本保留父版本、变化内容、事件原因和原稿证据；不要覆盖基础状态。

镜头声明连续性分支和故事时间，必要时指定准确继承镜头。按分支中的叙事因果解析状态；跨集、闪回和插叙显式建立继承。缺失前提或两个状态冲突时阻断受影响生成，向用户提出最小必要选择。

平行剧情会合使用 `stateSources` 按实体声明来源。可用 `stateFromShotId` 继承主要分支，再从其他分支覆盖指定实体；不要从另一分支整包拷贝状态，也不要通过无来源的 stateIn 手动拼出最终状态。所有来源必须不晚于当前故事时间。删除、修改任一来源事件后，检查会合镜头及后继镜头是否失效；无关闪回不应被重做。

例如外套完整 -> 镜头 12 发生撕裂 -> 外套破损；镜头 13、14 继承破损。只有换装、修补或明确回到撕裂之前的故事时间才能恢复完整。没有事件不能自动恢复。

镜头进入状态与其使用的参考状态必须一致。事件发生在镜头内时，提示词和首尾参考分别表达变化之前与之后；不能全段只引用最终状态。

## 用户素材

每项素材保留来源（用户上传、个人/团队素材库、生成）、准确来源记录、媒体类型、实体、状态和用途。供应商资源 ID、素材库 ID、画布节点 ID 和实体 ID 是不同概念。

优先复用准确可用素材。只凭相同文件名、相似人物或同一哈希不能判断服装/伤势/视角满足镜头需求。实际服装、伤势或破损变化保留状态和原因；镜头角度、动作、光照及持有者变化不自动要求独立图片。先判断已有参考是否足够，仅在镜头确需新视觉参考时建立素材变体，由用户上传或在有效授权后生成，供后续镜头复用。连续性状态、独立参考素材和画布节点分别规划，按 [工作流框架](canvas-workflow.md#素材复用与视觉变体) 控制呈现，不因节点精简丢失状态事实。

复用仍须满足当前准确状态与用途契约，不能将旧状态素材改标为新状态。基础身份参考与临时状态若无法按现有契约分别表达，说明具体缺口，不伪造绑定或盲目批量补图。参考图复用节省重复素材生成费用，不表示镜头视频或合成免费。

生成角色或场景变体时，默认以各自第一张已确认的基础图为母图走图生图，真实媒体必须进入模型支持的参考参数。角色变体保留身份依据，场景变体保留空间依据；已有准确变体继续复用。派生过程保留原始母图来源，必要时以前一变体作补充参考。缺少母图先补齐基础图，模型不支持时说明限制，不以单独文生图冒充图生图。具体规则见 [角色和场景变体的母图](canvas-workflow.md#角色和场景变体的母图)。

上传登记后读取真实登记回执；不能自动声称已经保存素材库、分享团队或绑定所有镜头。按用户选择继续持久绑定。失效链接、处理中资产或权限不明不能标记为可用参考。

## 修改与重做

更改事件或状态后计算受影响镜头，再使其提示词、参考绑定和产物检查失效。保留旧产物、任务号、扣费记录和未受影响的镜头。重新编写提示词不自动重做付费任务；按仍有效的授权范围继续。画布中手工修改与制作记录冲突时读取并协调，不能静默覆盖。
