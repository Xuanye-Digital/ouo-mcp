# OUO 共用制作与布局规则（自动生成）

由 `scripts/export_marketplace_catalog.py` 从 MCP 共用规则生成，不手工编辑。

规则契约：`ouo-canvas-workflow-guidance-v1`；修订：`3`。

适用于所有宿主的剧本工作流、分集制作及其布局。开工先读取并应用实时 `workflowGuidance`，包含 `productionRules`；服务缺少新字段时以本参考补齐，并如实说明版本缺口。工具、参数和真实能力以当前已授权连接的契约为准。本参考不执行生成，也不产生费用授权。

## 默认节点职责

- `source`：本集完整原稿，保留对白、场次和来源。
- `script`：本集主脚本，保存结构化分镜及角色、场景、道具对应。
- `shared_assets`：按稳定身份复用角色、场景、道具和独立音色，必要缺项使用真实媒体类型占位。
- `shots`：按已保存剪辑顺序编号，每镜只引用实际所需素材。
- `composition`：本集镜头按已保存顺序拼接。

## 分类与布局

- 用户明确结构和参考图优先。只整理选区时保留范围外位置、内容、参数及引用，已有分组调整须在授权范围内。
- 先列节点职责、素材类别、镜头顺序和复用关系，再安排内容区、分组与位置。同批创建和布局，超过限制时分区保存并继续完成布局。
- 角色、场景、道具和音色按类别形成可辨认的局部区域，名称写清实体与类别。可用类别组或共享区内的分类排列，不把混放素材的大框当作分类完成。
- 同类有足够成员且原生契约支持时建组。单个素材用明确名称和位置表达类别，不造空节点凑组，不为排版复制共享素材或修改业务连接。
- 原稿和主脚本相邻，视频按真实场次、连续段落和共同引用组织局部序列，合成靠近序列出口。用户需要的对齐与网格可以保留，不固定全图列数或随机错位。
- 按真实节点宽高、外置标题和分组边界留白，检查局部及邻近区域重叠。自动空位放置只解决落点，不能代替完整工作流的分类、分组和布局。
- 原稿和脚本不作为视频媒体输入。真实素材连接到使用它的分镜，并按当前 set_prompt 契约写入逐项指代的原生引用，待生成素材保留真实类型占位。
- 首轮工作流交付包含布局和分类复核。仅保存节点、线条或制作投影不能证明布局完成，也不证明素材已生成或提示词 Skill 已应用。

## 分镜、时长与状态

- 保留原稿的事实、说话者、原句、语言和对白顺序，区分对白、旁白与 OS。按实际叙事拆分镜头，不把完整台词压进无法容纳的短镜头。
- 逐镜依据动作难度、人物调度、对白、停顿和运镜估时，再选当前模型支持的组合，显式保存并回读实际时长；defaults.duration 仅为原生初始化值。
- 按集内剪辑顺序保存 editOrder，跨场剪辑不按故事时间重排。状态来源按真实叙事前驱显式绑定，闪回、并行段落和跨场状态不只凭节点位置、数组顺序或名称推断。
- 新写或获准改写提示词默认读取并应用对应内置图片、视频写作 Skill 的 writing。常规单图或单镜头可直接写作，三视图、复杂编辑、多镜头等需要具体写法时再读 patterns，示例按需。同一请求复用已读章节。用户明确选择其他依据时沿用其选择，原样保存用户正文时保留原文。

## 角色和场景变体的母图

- 每个角色和每个物理场景分别选定第一张已确认基础图作为母图，可来自用户上传、素材库或已核验生成结果；不按画布排序选图，不同身份或空间不共用母图。缺少母图先补齐基础图，沿用原有授权和确认范围，不新增逐张审批。
- 角色的换装、年龄、发型和形态，以及同一场景的日夜、布置、破损和视角变体，默认基于该母图图生图。描述改变的部分及保留的身份或空间依据，已有准确变体直接复用。
- 把真实母图媒体传入当前模型支持的参考参数；只写参考说明、原生 @ 或画布连线不代表模型已取得参考。保留母图、实体、状态、真实媒体来源和派生关系；继续参考前一变体时仍保留基础来源。
- 模型不支持图生图或缺少可用母图时说明具体缺口，不静默退回独立文生图；用户明确指定其他参考或制作方式时按其要求执行。生成仍需对应费用授权。

## 声音归属与逐镜绑定

- 每个实际发声角色分别保留独立音色入口、声音描述、准确音频来源和工具返回的真实声音标识，包括旁白、OS 和仅发声角色。占位或一句声音描述不等于已有音色，不共用默认音色冒充选声。
- 外观状态与声音归属分别判断，幼年闪回不自动改变成年旁白。音色需求使用 role=voice、mediaKind=audio，绑定准确 entityId 和声音基础 stateId；每个发声镜头在 assetRequirements 明确列出实际说话者的需求，无声角色不自动接入音频。
- 先复用准确音源，区分音色样本、声音标识与逐镜对白音频。按本镜实际发声者写入原生引用，并核对模型真实音频参考参数；所选视频模型不支持时保留独立声音计划和缺口，不把连线声称为模型已使用音色。

## 交付与生成前的编导审阅

- 交付可生成的工作流或开始媒体生成前，对实际内容完成适用的原稿保真、身份、镜头衔接、切点、轴线、连续性、对白、节奏和提示词审阅，保存实际 editorialReviews。仅整理位置或原样保存正文时不虚构内容审阅。
- 先保存内容并独立读取准确版本；跨页读取使用同一 expected_version。通过 editorialReview.targets 或 view=editorialTargets 取得准确范围的 episodeId 和 inputDigest，原样绑定本次 productionVersion，不自算或猜测摘要。
- 新记录使用 reviewer=agent 和实际 script_analysis 或 storyboard_review 方法，稳定 reviewId、范围、版本、摘要、结论及逐项实际证据一并保存，保留全部旧记录。未检查项用 not_checked，全部通过才可 passed；参数与引用核对不能单独替代内容审阅。
- 修改输入或遇到版本冲突时重新读取并检查受影响内容，追加新记录；核对 currentInputs 和 latestForTarget，历史、失效或被替代的记录不作为当前通过。编导审阅不代表媒体已检查，不授权改写用户正文或产生费用。

## 开工时核对合成能力

- 搭建分集工作流时即读取 get_production_contract 的 compositionLimits，核实用户所选画幅和当前合成能力，在生成片段前说明已知缺口。编辑契约的布局规则不能代替这一步。
- 当前 video_merge 只有已核验的 16:9 分辨率映射，其他画幅缺少已核验的比例控制。用户选择竖屏或其他比例时保留选择和已有片段，按已授权范围完成文本与工作流，整集合成保持未就绪，不静默改成横屏或添加收费转换。实际限制以实时 compositionLimits 为准。
- 首版仅按已保存剪辑顺序拼接；合成计划和参数以真实契约为准，不接入未授权的智能剪辑。

## 审阅身份、进度与媒体交付

- 新编导或媒体检查记录使用 reviewer=agent；旧 codex 值仅为历史兼容，保留原记录。没有已接通的可信用户评审入口时，不能新增 reviewer=user 或 method=user_confirmation，也不能把用户同意方案当作已完成媒体验收。
- 真实媒体检查保存到 reviews，绑定实际 outputId、检查时的 productionVersion、实际 visual_inspection、playback 或 metadata 方法及证据。没有看图或播放时保留未核验项，元数据检查不等于画面或声音验收。
- submit_generation 已返回进度卡时保留该卡，后台状态查询使用纯数据 get_generation_task。get_generation_result 或 show_generation_result 仅在用户要求重开或原卡确认缺失时使用，不在提交或查询后自动追加展示调用。
- 保存、独立回读、结果可访问、真实看图或播放和本地下载分别核实。超时、断线或受理未知时沿原请求、操作和任务核查，不换标识重提，不以重复生成恢复结果展示。

## 保存与布局检查

- 独立核实保存、节点职责、分组成员、素材类别、引用来源和剪辑顺序。
- 依据真实或有依据的估算尺寸检查节点、标题、分组和邻近区域，说明估算范围。
- 宿主可截图时检查准确画布的整体与拥挤局部。没有截图时如实标记视觉未核验，结构回读不代替视觉检查。
