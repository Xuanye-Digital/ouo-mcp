# 图片提示词编写与审阅

本文提供单项图片及制作中的角色、场景、道具、静态分镜的默认写作方法与保存约定；先按 [提示词创作与审阅](../../ouo-business-generation/SKILL.md#提示词创作与审阅) 选择写作依据，保留用户及所选 Skill 的风格和格式。视频过程另读 [视频提示词编写与审阅](video-prompts.md)。生成使用当前真实工具与模型契约。

## 内置写作 Skill

新编写或获准改写图片提示词前，默认调用 `get_image_prompt_guide(params={"section":"writing"})`。常规单图可直接写作，三视图、复杂编辑等需要具体写法时再读 `section=patterns`，示例按需。仅搭建工作流、只写角色/场景/道具或静态分镜提示词时同样适用。用户明确指定其他 Skill 或写法时由宿主读取和应用，原样保存用户正文时保留原文。同一请求复用已读章节。

区分单幅新图、已有图编辑、角色多视图、分格故事板、海报或扩图。沿用用户已给的主体身份、数量、外观、场景、姿态、风格、画幅、文字原句和修改范围；独立提示词任务不强制选择模型或未指定的比例、分辨率、背景颜色、人物数和禁字要求。短剧共享素材采用下述规格，用户明确要求优先。准备生成时另按实时契约补齐必要参数。

旧服务没有该工具时仍可使用宿主适用的写作 Skill，或以本参考兜底，如实说明实际依据。本地 Skill 提供文本方法，不代表媒体生成能力，不以此切换生成器或编造已读规则。

## 短剧共享素材规格

新建或明确改写共享素材时，角色图默认纯白背景、16:9 横幅、同一角色的正面 / 人物左侧面 / 背面全身三视图合为一张；道具图默认纯白背景、1:1 方图、单件物品或剧本明确的一组物件完整居中。白底须均匀纯白，不替换成浅灰、米色、彩色渐变或剧情环境。场景图和静态分镜按各自需求编写。已有准确素材优先复用，不按新默认值自动重做；用户明确的其他规格优先。

角色三视图从左到右等距排开，头顶至鞋底完整，整体尺度、脚底基线、身份、服装、体型与柔和中性光一致；使用中性站姿、自然垂臂和平视，不额外加入头像、表情小样、标注或装饰。道具保留轮廓、结构与材质，四周留白，不含人物、手持展示、桌面、布景或额外物件，不自动添加多视图或拆解图；必要原有标识保留。

以下两个示例的外观仅属于示例，实际使用时替换为已确认的角色身份、服装或道具设计，不能把示例设定写入用户剧本。

**角色标准图正文示例**：

```text
一张横向 16:9 的角色全身三视图设定稿，背景均匀纯白。从左到右等距排列同一位成年女性的正面、人物左侧面和背面，头顶高度、脚底基线和整体尺度一致，每个视图从头顶到鞋底完整入画，彼此不遮挡。

角色为齐肩黑色直发，穿灰色西装外套、白衬衫、灰色直筒长裤和黑色平底鞋。三个视图保持同一身份、身高、体型、发型、服装结构与配色，各部件按观察角度呈现合理遮挡。平视、中性站姿、自然垂臂，统一柔和中性光，保留衣料与主体体积明暗。画面仅有这三个全身视图和纯白背景，不加入剧情环境、彩色底、额外头像、文字标签或装饰。
```

**道具标准图正文示例**：

```text
一张 1:1 方形道具标准图，背景均匀纯白。一把黄铜钥匙完整居中，钥匙头位于左上、钥匙齿朝右下，四周留出空白，钥匙头、孔洞、细长钥匙杆和齿口结构清楚可见，不裁切边缘。

柔和中性光表现黄铜的金属光泽和细小磨痕，轮廓清晰，结构保持完整。画面只展示这一把钥匙，不加入人物、手部、钥匙串、桌面、剧情环境、彩色底、文字标签或装饰，不增加其他视图。
```

正文中的画幅描述服务构图，实际生成仍须按 [共享素材图规格](canvas-workflow.md#共享素材图规格) 设置参数：角色 16:9、道具 1:1，均独立于成片 `preferences.aspectRatio`。读取实时模型 schema 和 rules，显式写入实际支持的比例字段；一张三视图的输出数量为一张。完整参数保存在实际生成步骤的 `parameters.model_param`，有对应镜头图片阶段时同步该阶段 `modelParam`；保存后独立回读，不把文字、模型默认值或节点显示尺寸当作比例已设置的证据。原生控件未同步时如实报告；模型不支持目标规格时说明缺口，不静默改成其他比例。

生成后另查真实媒体宽高、纯白背景、视图方向、完整度和身份一致性；参数与提示词检查不代替画面验收。恢复原任务保留原参数与回执，不因新默认值重复提交或自动扣费。

## 写成可见的静态画面

- 写清主体数量、稳定称呼、位置、身体朝向、视线、持物和遮挡关系；区分画面左右与人物自身左右。
- 一幅图选择一个可见状态。视频式输入提取关键瞬间、观察角度和构图；运镜、时长、声音与剪辑要求不直接写成图像信息，没有分格要求时不擅自改成故事板。
- 让取景容纳需要展示的内容。全身要求头顶到鞋底入画；面部特写与全身展示可以分区，但不能同时占同一区域。
- 光源方向、软硬、冷暖、阴影和材质响应相容。把“高级”“超高清”等评价落实为视觉中心、空间层次、色彩关系、纹理与光比，避免重复画质标签。
- 风格作用于轮廓、体积、边缘、笔触、纹理与色块，不只堆叠写实、水墨、手绘、3D 等标签。

三视图区分一个角色与三个视图，统一设计、尺度、基线和光照，允许不同角度的合理遮挡。分格图写清一张合成图或多张独立图、行列、阅读顺序与各格状态；整体比例与单格比例分开。**成图张数、人物数、视图数、分格数分别核对**，一张三视图或九宫格不自动拆成多次生成或多张报价。

文字用引号保留准确原句、标点、大小写和数字，指定位置与层级。无文案不编造品牌、价格或宣传语；区分“无额外文字”和“不出现任何文字”，避免与保留产品标识或可读标题冲突。

## 编辑与扩图

先写目标区域与改成什么，再写有必要保留的属性；不能改姿势又锁定姿势完全不变。替换和新增内容的透视、尺度、遮挡、受光与接触阴影要与保留部分相容。去除物体后补齐背景，不画出选区和涂抹痕迹。

扩图写明方向、成图比例与原内容保留范围，延续边缘空间和光影，不复制主体。扩图、重裁切和改变观察角度分别描述；未看到原图时不臆造细节为已知事实。已有角色或场景变体的母图与身份保持依据按 [连续性与素材](continuity.md) 保留。

## 素材绑定、审阅与保存

提示词正文不包含素材引用标记或绑定说明。正文保留所选写作格式；素材另按当前模型的真实字段绑定，画布需要原生引用时先连接准确媒体，再通过 `set_prompt.parts` 交错传文字和 `kind=reference` 的 `source_node_id`、`media_kind`、`output_index`。由现有保存路径编译所需标记，不手写普通“@角色名”，不删除已有有效绑定。空占位按实时契约保留来源，不冒充已生成素材。

画布编译提示词逐项指代每个素材的具体主体与用途，例如“女主外观：原生引用；银行经理外观：原生引用；营业厅场景：原生引用；女士鞋：原生引用”，不只在“人物外观”等类别后堆放引用；准确 `parts` 写法和回读检查见 [角色音色与引用](canvas-workflow.md#角色音色与引用)。这不改变创作正文与模型实际媒体绑定各自的保存职责。

在制作记录中，有对应镜头图片阶段时，图片正文保存到 `stagePrompts.generate_images.text`，模型专用编译正文、参考及参数保存到该阶段 `modelParam` 并审阅；共享实体图保存在对应图片节点及实际生成步骤的 `parameters.model_param`，不为保存素材提示词虚构叙事镜头。实际请求须与已保存版本一致。按用户要求同步对应脚本 `shotPrompt` 与图片节点，视频 `stagePrompts.generate_videos` 和 `motionPrompt` 独立保存。模型、分辨率和比例使用参数控件，素材库身份、任务号和管理 JSON 不进入创作正文。

按用户目标、所选写作依据与模型契约审阅实际内容，不以与内置示例相似判通过。新编写或获准改写的正文再按本次任务核对主体、数量、构图、文字、编辑范围和约束，修正具体问题；用户只要求原样使用时保留原文，不借审阅改风格或格式。交付采用用户要求的格式。保存后独立读回正文、编译引用、参数与版本；文字审阅不代表真实画面、身份保持或文字渲染已验收，也不产生费用授权。后续生成继续遵循 [生成与预览](../../ouo-business-generation/references/generation.md)。
