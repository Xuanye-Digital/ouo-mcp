# 剧本与分镜制作规则

用于原稿分析、角色场景道具提取、分镜规划和提示词审阅。实际生成仍须使用当前工具支持的模型、参数和费用授权。

## 原稿与分集

先建立每场的目标、冲突、转折与叙事作用，再决定集间断点。按原稿实际结构工作，三幕式可以帮助分析，不强制改写原故事。完整覆盖开头、独白、回忆、场景切换和结尾事件。第一轮提取后，独立重新扫描全文核对遗漏。

剧本已定稿时保留原对白、语言和顺序，不用摘要或省略号代替。故事创作、补充静态视觉设定与事实提取分开记录。不得为了让结果更丰富，创造原稿没有的亲属、真实姓名、服装变化、道具功能或场景结构。

## 角色、造型、声音

先归一同一人的别名与称谓，再建立不同年龄、形态、服装和伤情版本。完整与破损服装分成不同状态，共用角色身份；不能按核心名去掉视觉版本。

有单独动作、对白或被明确识别的可见人物应提取，不能因戏份少漏掉。仅电话、广播或画外发声者保留声音归属，不擅自为其生成立绘。纯背景人群不硬拆成许多独立人物。

角色身份记录性格、目标、障碍和声音特征。参考图描述按实际需要采用单人静态形象，动作、站位、环境与镜头运动放在分镜。用户已有参考时冻结其身份与视觉设定；缺少设定时的视觉补全标明是创作选择。

短剧新建共享角色图默认纯白背景、16:9 横幅，在同一张图中从左到右展示同一角色的正面、人物左侧面、背面全身三视图。统一身份、服装、体型、尺度、脚底基线与中性柔光，每个视图头顶至鞋底完整，不加入剧情环境、彩色底或额外头像。必要角色变体保持母图身份及同样规格；用户明确要求优先，已有准确素材不自动重做。

画面可见角色、发声角色、年龄形象和音色引用分别保存。可见不等于发声；成年叙述者不能因闪回出现幼年形象就换成幼年声音。

## 场景和道具

以真实空间边界区分场景：内外、独立房间和隔离功能区通常分别建档；同一空间的窗边、门边、墙角可共用基础场景。跨集相同地点复用同一实体，日夜、损坏和布置变化保存为状态，不按集重复创建相同素材，也不合并有实际差异的状态。

独立场景图描述空环境，不混入角色及对白。用户已有场景参考时，不擅自添加建筑、家具、招牌、材质或天气。新设计明确区分原稿事实与补充设定。

道具关注持有、交接、使用、损坏和丢弃。转手仍是同一个物件，不因同名合并不同钥匙或信件。固定建筑归场景，可移动的具体器物归道具。生图用物件本体描述，剧情尺寸与空间关系另存，不能因独立物件提示词的简化丢失剧情事实。

短剧新建共享道具图默认纯白背景、1:1 方图，完整居中展示单件物品或剧本明确的一组物件，关键结构与材质清楚、四周留白。持有者、手部、桌面和剧情环境不进入道具标准图；保留必要的原有标识，不自动添加多视图或拆解图。用户明确的其他规格优先。角色与道具图分别设置实际生成比例，不继承成片画幅；场景图保留真实空间，不套用白底规格。

## 两层分镜

先拆叙事小镜头：每条推进动作、信息或视点，连续动作保持连贯。可见行为写画面，实际播放的文字另存，并标记对白、旁白、内心独白、画外音或无声。独白和 OS 不改为开口说话。

再按所选模型实际时长限制，将相邻小镜头组织为可生成片段。优先在动作或语义完成、地点变化、叙事节拍结束处切开。执行前读取当前模型契约，不沿用其他任务的时长约定。

每个片段从 0 开始计时，子镜区间连续、不重叠，结束点等于总时长。中文对白可以用字数/约 5 字每秒并加停顿作初估，最终以实际语速和音轨为准；其他语言按朗读估算。时长不足时拆分或调整片段，不能删句或压成不自然的快读。

## 提示词保护

只引用已确认角色、场景、道具与声音，名称/ID 不因翻译或润色改变。采用 `@[character:...]`、`@[location:...]`、`@[prop:...]` 或 `@[voice:...]` 的内置接口时，对照准确白名单；普通模型不支持标签时编译为其真实参考参数，不假装标签天然有效。

润色不得新增或迁移发声者，不改变对白内容、语种和发声类型。保留既有时间段。当前接口明确要求 `说：{...}`、`内心独白：{...}` 等格式时保持结构；不能把参考标签插入实际播放的文字。

已有资产时只优化动作、位置、朝向、互动、表情及有依据的临时状态。身份外观、服装、环境事实和道具材质保持冻结，变化必须有对应事件或用户明确的创作修改。

## 交付核对

将镜头里的全部口述按原顺序拼接并对照原稿；核对发声归属、资产白名单、时间区间和状态事件。移除无意重复的相邻镜头，但不能删除独立信息或对白。结构化输出不伪造模型、任务号、计费、token 或结果地址。

这些规则支持编导审阅，不证明真实生成已符合要求。产物需另行查看，检查动作接点、状态、声音和最终剪辑。
