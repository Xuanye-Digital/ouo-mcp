# 导演与表演调度

用于人物动画、白模预演和运镜设计。先解决观众要理解什么，再选择姿态、机位与运动。具体 Blender 实现及交付检查见[镜头制作与验收](blender-shot-workflow.md)。本文是基于文末专业资料整理的制作方法；示例、记录格式和验收约定由本项目制定，不是来源原文或固定艺术公式。

## 先确定场面的叙事任务

按当前原稿与用户要求，确认这一场开始和结束时发生了什么变化：谁获得信息，谁失去主动，关系或风险怎样改变。对白、动作和原有因果顺序保持准确。可以推断表达方式，不能把推断写成原稿事实。

将场面拆为会改变意图、策略、信息或注意对象的节拍。不要按每句对白机械拆镜；一段连续行动可以经过多个节拍，一个节拍也可用主镜头、反应或细节镜头共同呈现。

每个关键节拍回答：

| 决定 | 必须落实到画面的内容 |
| --- | --- |
| 角色目的 | 他想让对方做什么、相信什么，当前阻力是什么 |
| 表演动作 | 用可执行的行为表达策略，如试探、安抚、躲避、施压；不只写“很紧张” |
| 刺激与变化 | 哪个声音、动作、话语或发现触发了新的判断；转折前后有何可见差别 |
| 观众信息 | 此刻应该看到谁或什么，应该知道多少，哪些信息暂时保留 |
| 镜头任务 | 关系、表情、动作、接触点或环境中哪一项必须读清；何时到位、何时离开 |
| 结束状态 | 人物站位与朝向、视线、道具归属、动作阶段，怎样交给下一节拍 |

对白的潜台词用于选择表演，不替换原话、发声者或语言。人物背景、关系和心理只有原稿或用户支持时才当作设定；不确定时选最少附加假设的演法。

## 把意图变成可读的表演

反应必须对应角色能够感知的刺激；遮挡、画外或背后事件不能让人物无缘无故提前知道。考虑听见、注意、理解和选择行动的过程，但不强制每次都演成固定四拍，也不规定统一反应延迟。细小的停顿、眼神或重心变化可以比大幅动作更有效，幅度取决于风格与景别。[角色反应资料](https://www.animationmentor.com/blog/animating-convincing-character-reactions/)

- **听与反应**：非发言者仍在听、判断或压抑反应；不持续对每句台词点头。决定观众需要看说话者、听者、双方关系还是被谈及的物件。
- **视线与朝向**：分别设计眼神目标、头部朝向和身体朝向。人物可以回避对方、边走边说或背对镜头；有表达目的时保留，不把所有台词修成正面站定讲话。
- **姿态与重心**：先明确支撑脚、骨盆与胸廓的关系，再设计伸手、坐下、起身或转身。动作有重量和可行的平衡；表现疲惫、抵抗或迟疑时改变支撑和节奏，而非随意抖动整个角色。
- **动作层次**：用关键姿态表达准备、主要行动、接触或转折、收势；为转折加入必要的中间姿态。头、肩、躯干和肢体可以错开运动，幅度服务于人物，不把每个部位同时启动、同时停止。
- **停顿**：分清思考、等待、压迫、反应和动作稳定所需的停顿。保持姿态也可以有微小呼吸或重心变化；需要压抑或静止时不强行添加“生动”小动作。
- **道具互动**：明确哪只手、接触点、受力方向、拿起与放下时刻，以及物件从谁转到谁。关键物件的轮廓和接触过程必须能看清，不能靠提示词说明被挡住的交接。

关键姿态、动作预备、时间分配、弧线及跟随动作可用动画基础原则检查。白模优先表达行动与时间，不为展示所有原则加入原稿没有的动作，也不对写实表演强加夸张变形。[动画原则资料](https://www.animationmentor.com/blog/tutorial-12-principles-of-animation/)

### 代理角色的表达范围

角色保留稳定名称、身高比例与颜色映射，中性头部可增加简单朝向标记。需要表达坐、蹲、抓握、指向或交接时，用足以读清该动作的躯干、关节或手部代理；单一刚体圆柱不能被报告为已经验证了这些动作。

若场面转折完全依赖表情、眼球或口型，而代理没有对应结构，白模只验收机位、朝向、节拍与动作；把面部表演和口型留给具有该能力的角色工程或后续成片验收。不能用旁注替代本应可见的表演。

## 用调度管理观众注意力

先建立人物、出口、障碍和关键物件的关系，再安排机位。用主体大小、明暗、深度、轮廓、视线和运动分配注意力。通常为每个关键时刻安排明确的主要注意对象；群戏中的同时行动可以保留，但必须说明观众如何读出各条信息。

当注意从 A 转向 B，给出可感知的引导，如 A 的目光、声音方向、B 的预备动作、前景让位或构图变化。背景动作保持与情境相符的强度，避免在核心反应发生时用无关大动作抢视线。调度要从最终摄影机检查，工作视图里的清晰不等于银幕上可读。[注意力调度资料](https://www.animationmentor.com/blog/tutorial-use-character-staging-to-guide-viewer-focus/)

遮挡可以制造悬念或表达关系，但关键揭示必须在计划的时刻真正出现。拍摄人物手部或物件细节时检查尺寸、遮挡和停留时间；表演的决定性信息不能在镜头尚未到位时已结束。

### 空间、视线与连续性

- 在俯视布局上标出当前对话轴线或运动轴线、摄影机所在侧、人物银幕左右和出入画方向。多人互动时按当前关系检查，不能一条固定轴线套完整场。
- 正反打核对双方视线的方向与高度、镜头的客观或主观视点、过肩前景及人物大小。视线指向同一对象不代表两人都应在画面中朝同一边看。
- 连续动作切换机位时保留动作阶段、运动方向、道具所在手及落点；选择剪辑接点时实际比较前镜末端和后镜开端，不能仅凭时间码相邻认定接上。
- 同主体相邻镜头还要检查视角和景别变化是否形成清楚的新观察；两个过于接近的机位可能产生无意跳切。通过实际接点判断，不把固定角度差当作适用于所有场面的合格线。
- 需要换轴时，可让观众看见摄影机或人物越过关系线，或用清楚的中性/重新建立空间的镜头过渡。故意跳切、越轴或迷失方向必须有当前故事或风格依据，并注明希望产生的感受，不能一律当成错误修掉。
- 改变注意对象不等于必须切镜；原镜头内的走位、重构图和焦点变化都可以完成。切镜也不必等台词说完，画面与声音可有意错开，但不可丢字或改变归属。

连续性规则帮助建立可理解的空间；有意违反可以成为表达手段。BFI 对电影创作者的访谈提供了跳切和越轴服务于冲击感的实例，不能由此推导每场都应打破规则。[创作实例](https://www.bfi.org.uk/interviews/psycho-shower-scene-alfred-hitchcock)

## 选择机位与运动

先决定视点、人物关系、画面要包含的信息，再决定摄影机是否移动。固定机位是完整的表达选择；一镜到底或多镜切换服从用户要求、表演和场地。不要用运镜数量衡量专业程度。

ASC 的摄影实践强调从剧本与导演意图选择移动方式及可用设备。本项目将它落实为每次移动记录“触发原因、注意对象、起止构图、速度变化、停留和路径条件”。[ASC 运镜资料](https://theasc.com/article/shot-craft-camera-movement/)

| 手段 | 可以承担的任务 | 设计时要回答的问题 |
| --- | --- | --- |
| 固定、保持构图 | 观察关系、等待反应、让细小动作产生分量 | 画面内部是否已足以引导注意；保持到什么事件才结束 |
| 摇摄/俯仰 | 在一个位置转移注意、跟随动作或揭示高度关系 | 起止对象为何关联；到位时信息是否仍在；是否误当成机位移动 |
| 推近/拉远 | 靠近人物判断，或扩大关系与处境 | 哪个节拍改变距离；近处透视和背景视差是否符合意图 |
| 横移/跟拍 | 保持行动关系、揭示纵深、陪伴人物 | 摄影机领先、并行还是落后；主体速度与银幕位置怎样变化 |
| 弧线/环绕 | 改变关系、显露被遮信息或改变视点 | 转到哪一侧才有新信息；轴线、背景和出路是否仍可读 |
| 升降 | 从局部扩展到地理关系，或强调人物与环境比例 | 高度变化为何发生；是否具备足够场地和合理运动方式 |
| 变焦 | 保留机位而改变视野与画面中主体大小 | 为什么不移动机位；是否明确需要变焦的视觉语言 |
| 转焦 | 在同一构图里转移前后景注意 | 前后目标是否实际可见；何时到焦；焦点变化是否会抢走表演 |
| 手持感 | 建立特定观察方式、紧迫或不稳定体验 | 抖动的尺度与频率是否可读；是否只是无目的的随机噪声 |

摄影机应在需要读清的信息发生时提供适当画面。可以在台词前到位，也可以有意随说话过程揭示；不规定所有句子必须等镜头停稳。移动的加减速、转向、停留和最终稳定都按节拍设计，避免从起点到终点全程机械匀速或每个关键帧都停顿。

### 景别、焦距、距离与画幅

先用景别确定需要读清的内容：关系需要双方与空间，反应需要足够的人物尺度，交接需要手和物件。全景、双人、中近景、细节及反应镜头是选项，不是每场必须拍全的清单。

- 记录实际画幅、传感器尺寸和适配方式，焦距毫米数才有明确语境。短焦距并不自动“更有电影感”，长焦距也不自动表达某种情绪。
- 摄影机位置决定观察的透视关系；同一位置单改焦距主要改变视野。为了保持人物大小而同时移动机位，会改变前后景的相对关系。不要将变焦当作推轨，或为修复构图随意改变房间尺寸。
- 高度、俯仰与人物眼线结合判断；高低机位的意义依赖上下文，不能固定解释为强弱。明确主观镜头是谁的感知，不让摄影机在无依据时拥有角色不知道的信息。
- 留意头顶空间、视线方向空间、运动余量、肢体切边、背景切线和前中后景分离。居中、对称、负空间都可成立，按当前意图选择，不能机械套三分法。
- 横屏与竖屏按目标画幅重新构图和调度；不先做横屏再直接裁掉关键反应或手部。白模先保证动作与空间可读，浅景深和运动模糊按表达需要启用。

摄影机视野、传感器、对焦及画幅适配以当前 Blender 版本为准。[官方摄影机文档](https://docs.blender.org/manual/en/latest/render/cameras.html)

## 写出能够执行的分镜计划

使用当前任务目录中的简短 Markdown 表或已有项目分镜即可，不建立额外服务或数据系统。计划完成后在原授权范围内继续制作，不默认要求用户逐镜审批。逐镜保留以下实质信息，用户已有可用格式时沿用：

- 镜头标识、场景与叙事目的；全片与本镜的起止时间及后续换算出的帧范围。
- 节拍的注意对象、角色目标、触发事件、可见行动与反应；角色走位、朝向和目光目标。
- 原句台词、发声者、声音类型与来源；动作、台词、反应是否有意重叠。
- 起止景别、摄影机位置/高度/朝向、焦距与传感器；需要时记录焦点和路径控制点。
- 摄影机移动起止、目标到位、重要接触、揭示、停留与切点；每次改变的叙事理由。
- 出入镜状态、轴线与道具归属；下一镜接什么，以及对应的验收画面或播放区间。

## 示例：两人交接与决定

仅说明设计粒度，不是未来任务的固定剧情。假设用户给定：A 把信封放到桌边；B 问“你确定？”；A 迟疑后答“我只知道这些。”；B 收起信封，说“那就走吧。”；两人离开。目标 12 秒，24 fps。没有实际音轨时下表时间是排练估计，不能当作已核实语速。

| 时间/镜头 | 行动、声音与观众注意 | 摄影机选择和理由 | 接点/验收 |
| --- | --- | --- | --- |
| 0-3 s / S01 | A 放下信封，手离开后保留 B 的观察；B 在约 2 s 发问 | 同侧双人中景，手与物件可见；固定观察空间关系 | A 不提前回答；信封确实接触桌面，B 的目光对应物件与 A |
| 3-6 s / S02 | A 的犹豫先被读到，再说原句；B 的听者动作保持克制 | 切到 A 的中近景，小幅推近在约 3.8 s 到位，再让台词承重；此时间为当前演法选择 | 反打轴线与眼线匹配；正常速度下迟疑有可读时间，没有被推镜抢走 |
| 6-9.5 s / S03 | B 伸手取信封并收进外套，随动作说原句；A 开始准备跟随 | B 的中景包含手与衣袋，不切成看不到交接的脸部特写 | 桌面到手到衣袋的状态连续；说话和收势可以重叠，不变成统一先动后说 |
| 9.5-12 s / S04 | B 引领离开、A 跟上；注意回到两人的关系和出口 | 回到能容纳二人的较宽机位，按实际距离选择保持或短距离横移 | 出画方向、步行距离与剩余时间可行，末尾没有截断必要行动 |

若用户改为一镜到底，保留上述信息顺序与表演，用连续路径和人物让位重新设计构图；不把四个机位间瞬移当成连续镜头。若要求无声，保留表演节拍并按用户意图处理对白呈现，不能自行生成配音。
