# Blender 镜头制作与验收

将[导演与表演调度](directing-and-blocking.md)中的分镜落实为用户本机可重开的工程和真实预演。使用当前 Blender 的 `bpy`、现有工程或已有连接；以下是制作与检查方法，不要求新增插件、固定 Rig 或自动评审系统。

## 1. 锁定制作条件和时间基准

先读用户已有工程、参考与输出要求，确定单位、空间尺度、画幅、分辨率、帧率、起始帧和所需时长。只为当前任务补充缺少的制作信息，已有准确条件直接沿用。

- 摄影机位置与物体尺寸使用相同场景单位；说明单图推测的尺度，保留真实测量值。低成本预览可降低渲染分辨率、采样和材质成本，但不改变用户要求的时长、动作时间或画幅。
- 有真实对白音轨时，以实际音轨、语速、呼吸和停顿安排表演。临时朗读或文本时长只能作排练估计；不得为塞进时长吞字、改句或悄悄加速音轨。冲突时优先调整镜头安排，必要时说明原规格无法同时满足。
- 无明确帧率时按目标交付选择并记录，不在制作中静默切换。实际每秒帧数 `fps_effective = fps / fps_base`；分数帧率同时保留分子、分母，不能把 23.976 当作精确 24 来反复累计。
- 以全片从零开始的时间建立切点，统一换算 `boundary(t) = start_frame + round(t * fps_effective)`；相邻镜头共用同一个已量化切点，不分别累计四舍五入的镜长。整数渲染帧范围是本镜起点至下一切点减一；所有尾界以半开区间解释。
- 量化后切点必须严格递增，每镜至少一帧，不能颠倒原事件顺序。两个事件落在同一帧而无法读清时，重新分配时间或说明规格冲突，不能保留零帧镜头假装覆盖。
- 末界只作时间边界，不再额外渲染一帧。量化时长与请求时长的误差说明到一帧精度；关键声音对齐还需实际播放，不能用帧公式替代听音。

例如 12 秒、24 fps、从第 1 帧开始，片尾边界为 289，总计渲染 1-288 帧。示例的 0/3/6/9.5/12 秒切点对应 1/73/145/229/289，因此四镜范围为 1-72、73-144、145-228、229-288。镜头内时间可从零记录，但转到工程前明确其全片偏移。

## 2. 先把表演摆清楚

用俯视布局核对角色、出口、障碍、道具和摄影机通道。可用地面标记辅助排练，不把辅助标记烘进最终参考视频。代理的简化程度服从实际需要表达的动作。

1. 先在关键节拍摆出清楚的姿态与朝向，用阶梯插值检查信息顺序、目光目标、接触及人物关系。此时只验证姿态和大致时间，不把阶梯播放判为最终自然运动。
2. 补足动作分解姿态，特别是脚步落点、转身、坐下起身、伸手接触与道具释放。身体需要有支撑与重心；有步行动作时检查落脚是否在地面滑动，不能只把圆柱平移当作步态验收。
3. 再调整插值、弧线、快慢、停留和部位错开。阶梯转平滑后重新看全段，原先的反应时间与接触可能已被插值改变；不能用默认平滑代替表演设计。
4. 道具持有关系只在实际接触或释放处变化。使用父子关系或 `Child Of` 等现有约束切换时保留世界变换，核对切换前后帧，防止物件跳位。坐姿、手部与物件需要时可用已有骨骼或简单关节，不强行制作完整人物资产。

姿态到姿态及不同插值的适用范围参考[动画教学](https://www.animationmentor.com/blog/tutorial-use-character-staging-to-guide-viewer-focus/)和[Blender F-Curve 文档](https://docs.blender.org/manual/en/4.5/editors/graph_editor/fcurves/properties.html)；具体操作以用户当前版本为准。

## 3. 分开控制摄影机的三个任务

| 控制 | 制作要点 | 常见错误 |
| --- | --- | --- |
| 位置与路径 | 起止点、必要中间点、通道宽度、主体相对距离、转弯与高度变化 | 路径两端正确，中途穿桌、穿墙或掠过角色 |
| 朝向与构图 | 注视目标可与人物根节点分离；为眼睛、手部、物件或反应设置实际注意位置 | 始终看向人物原点，镜头只拍腰部；换目标时突然甩头 |
| 焦距与焦点 | 固定并记录镜头语境；焦点随实际距离或专用目标控制，有意转焦记录起止 | 目标在画面里却始终失焦；靠变焦补偿所有走位 |

可以使用关键帧、路径约束或现有摄影机 Rig。摄影机沿路径移动时，路径参数线性变化不保证空间速度恒定；曲线长度、控制点和时间曲线需要一起检查。`Follow Path` 的位置与自动朝向是不同控制，不能认为启用路径就已完成最终构图。[官方路径约束文档](https://docs.blender.org/manual/en/4.5/animation/constraints/relationship/follow_path.html)

- 使用朝向约束时核对摄影机局部朝前/向上轴和滚转，检查目标经过摄影机或接近奇异朝向时是否翻转。用 Euler、Quaternion 或 Rig 都可以，但旋转插值不能出现无意长绕或跳变。
- 跟拍需要设计主体在银幕上的位置与运动余量；有意滞后、领先和重新对准必须能解释。不能把相机和人物根节点绑死后就认定伴随感成立。
- 速度曲线按镜头意图设计。保持匀速的中段、平滑起停或突变都可能合理；无意的自动手柄过冲、弹回、漂移和每个关键帧停顿需要修复。修改控制点后复查相邻区间，平滑曲线可能连带改变前后段。
- 以最终画幅查看关键帧及中间运动。粗检可用投影坐标、射线、包围盒或距离帮助定位风险；这些检查不能代替实际画面的可读性，也不能用稀疏采样证明全程无碰撞。
- 检查近裁剪、墙体、前景、过肩人物和手持道具；不通过隐藏墙体或缩小角色掩盖不可行路径。实拍风格的通道保留摄影机装置与操作空间的合理性；用户明确要求虚拟穿越时按其创作意图处理并注明。

## 4. 将节拍落到同一工程时间线

每个关键事件都能对应分镜和工程帧：角色进入、注意转移、动作预备/接触/释放、台词起止、摄影机到位、揭示与切点。名称足以识别角色和事件即可，不要求新增固定数据 Schema。

- 使用 Timeline Marker 记录关键事件，必要时将分镜计划保存在 Blender Text 数据块或同目录文档，便于重开定位。Marker 是事件索引，本身不会执行人物动作或生成声音。
- 多机位切换需将准确摄影机绑定到切点 Marker，或用当前工程已有的逐镜渲染方式。普通文字 Marker 不会自动切镜；重开后逐个切点核对实际活动摄影机。[官方 Marker 文档](https://docs.blender.org/manual/en/4.5/animation/markers.html)
- 连续镜头不允许在相邻关键帧之间直接跳到另一机位；若有意隐藏切点，必须在实际预演中成立，并符合用户的一镜到底要求。
- 本地预演的剪辑可使用 Blender 现有剪辑能力连接已设计的镜头，保持时间与声音对应。后续 OUO 首版成片仍按既有镜头顺序拼接，不引入智能剪辑流程。
- 真正提供对白、临时配音或音效时记录来源及用途。无音轨时交付无声预演并标明未验证音画；不把台词标记、口型占位或脚本中的声音描述报告为已经发声。

## 5. 用预演逐步检查

先看关键姿态与接点，再输出完整时长、连续运动的低成本预演，正常速度看过后定位问题帧。不要先高质量渲染一整片，再用几张漂亮截图交差。

| 检查阶段 | 观察和修复对象 | 能支持的结论 |
| --- | --- | --- |
| 分镜与原稿核对 | 全部原话、发声归属、事件顺序、角色目的与镜头任务 | 计划没有已发现的内容遗漏；不能证明画面已实现 |
| 关键姿态与俯视布局 | 空间、支撑、朝向、物件接触、机位与画幅 | 已查看的姿态和布局；不能证明中间运动 |
| 连续帧与曲线 | 接触前后、切点两侧、路径拐点、视线转移、裁剪与过冲 | 所检区间的具体问题与修复；稀疏采样不能证明全片 |
| 全时长正常速度播放 | 观众注意、反应是否读到、速度、停留、动作重量和剪辑节奏 | 已实际播放范围的运动与叙事可读性 |
| 实际听音及音画对照 | 字句、说话者、停顿、同步、音效与声画跨切 | 已听范围的声音；无声白模或未听音不能通过此项 |
| 最终工程重开与输出核对 | 机位切换、帧范围、外链、实际时长、分辨率、帧率及可播放文件 | 可恢复和媒体规格；不自动证明表演质量 |

播放时先按普通观众速度看一遍，写下“在何时看到什么、因此理解了什么”。再按时间码逐项检查，不根据已读剧本替观众补上画面没交代的事实。宿主无法播放时保留文件与连续帧检查结果，明确正常速度和听音仍待验收。

### 动画交付的判定

以下各项按任务适用性写为“通过 / 失败 / 未验证 / 不适用”，并附镜头或时间码、查看方式与具体观察；不能将未验证归为通过。

- 原稿要求的关键动作、对白和转折完整；明确选择的留白、画外或延后揭示有依据。
- 决定性动作、接触或反应发生时，所需画面实际可见且有足够阅读时间；旁注没有替代画面。
- 摄影机移动、保持和切换能解释其叙事任务；正常速度下不出现无意抢拍、甩动、漂移或迟到。
- 人物视线、动作阶段、物件持有与出入画方向连续；有意越轴或跳切有明确记录和可见效果。
- 具有足够代理结构的动作无已发现的穿模、浮空、滑步或抓握跳位；简化模型不能表达的部分已具体列为未验证。
- 请求的对白字句、归属和声音类型保持准确；实际声音的有无、来源与检查范围如实说明。
- `.blend` 可重开；计划、脚本、镜头与输出对应；实际 MP4 可解码、时长与规格符合要求，不能仅根据渲染配置声称合格。
- 上传与画布保存沿[本地执行与上传](local-bridge.md)单独核实。动画合格不代表已经上传；画布有节点不代表动画合格。

先修复内容遗漏、信息不可见、断接和穿模，再调节表演与节奏，最后处理非必要的画面润色。更改走位会影响构图与相邻接点；更改时长会影响声音、切点和后续偏移，按实际依赖重查，保留未受影响成果。

### 检查方法的反例

| 情况 | 正确判定或处理 |
| --- | --- |
| 推镜末帧正确，但关键台词发生时还在绕到人物背后 | 查对应时间的实际画面，判断是否丢失所需信息；不凭末帧通过 |
| 两张端点图都不穿墙，中间路径经过墙体 | 动画不能通过；修路径并检查整段，而非只移动端点 |
| 接物件瞬间换父级，物件跳到掌心另一侧 | 回查接触前后帧和世界变换；修复后重新检查动作与切点 |
| 灰头圆柱按时转身，但要求的眼泪与口型无对应结构 | 仅能通过朝向和时间；面部及口型未验证，不描述成已完成表演 |
| 只导出一张时间线截图，所有 Marker 名称都存在 | 只能证明标记存在；不能证明切镜、动作、声音或实际视频 |
| 无声白模里有完整台词文字 | 可以交付无声预演，但声音、语速及音画同步未验证 |
| 用户有意要求越轴制造失衡 | 依其意图检查是否实现，并记录；不能套规则擅自改回同侧 |
| 静态场景或产品展示没有人物对白 | 不强加人物表演、反打或配音，按当前展示目的检查 |

## 白模到成片的交接

仅在用户要求继续生成时执行。保留当前已确认分镜、原视频、准确版本和时间基准，不凭节点连线假设模型接收了媒体。

| 输入 | 给模型的职责 | 不应继承的内容 |
| --- | --- | --- |
| 白模视频 | 镜头运动、人物位置与走位、动作接点、时序、剪辑与时长参考 | 代理肤色、灰球头、圆柱身体、粗糙家具与白模材质 |
| 已有场景参考 | 建筑、家具、材质、光线及空间一致性；多视角存在时共同约束 | 不能为补参考随意改变原空间或重新独立设计另一房间 |
| 已确认角色/状态参考 | 身份、服装、体型、必要版本及道具关系 | 三视图排版、白背景或将不同状态混为同一造型 |
| 实际音轨或对白要求 | 准确字句、说话者、语言、声音类型及时间；按当前能力提供 | 不支持音频参考时不能伪造绑定或声称保留了原声音 |

生成前读取当前模型的真实模式、视频/图片/音频参考字段、数量、文件规格、时长和声音能力；优先复用已有准确素材，不强制生成两张场景图或角色三视图。缺少表达能力时指出具体缺口，不静默丢掉白模、快放压缩时长或改成不等价模式。

提示词按镜头和时间写清动作、注意对象、相机、原话与反应的关系，明确每个颜色代理对应哪个角色；同时说明外观来自场景和角色参考。实际媒体必须进入模型支持的字段；文字 URL、角色名称和画布连线均不能代替该输入。

按现有费用确认与原任务恢复规则提交。成片需重新查看，逐镜对照白模运动、空间、角色身份、表演、道具与实际声画；白模已通过不代表生成视频会自动遵循。几何/运镜问题回到相应镜头修白模，外观或身份问题检查参考和生成参数，付费重做仍按有效授权执行。
